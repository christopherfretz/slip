## Interface

```rust
// admission.rs — pure: no clock, no processes, no I/O.  (§6)
pub struct Config { pub budget: u64 /* 0: no admission, no caps */, pub estimate_base: u64, pub estimate_per_byte: u64,
                    pub observer_memory: Option<u64>, pub worker_stack: u64 }
pub fn budget_from_system(cgroup_max: Option<u64>, total: u64) -> u64;      // "Budget", second sentence
pub fn read_system() -> (Option<u64>, u64);                                  // cgroup v2 memory.max, MemTotal; (None, 0) if unknown
pub struct Admission;    // estimates, reservations, skip counts, alone mode, pressure and cap decisions
//   new(config, previous: &HashMap<Digest, u64> /* peak_rss by observer from the last run record */)
//   estimate(&Observer) -> u64;  rss_cap() / address_space_cap() -> Option<u64>
//   pick(&mut self, pending: …) -> Option<…>      the next job to start, or none ("Admission")
//   started / finished / requeued bookkeeping
//   on_samples(&mut self, samples: &[(JobKey, u64)]) -> Vec<Decision>   Decision = KillAtCap(job) | KillForPressure(job)

// pool.rs — the coordinator.  (§5.3, §5.4, §7)
pub struct WorkerCommand { pub program: PathBuf, pub args: Vec<OsString>,
                           pub env_remove: Vec<OsString> /* variables the worker must not inherit */ }
pub struct Options { pub jobs: usize, pub admission: admission::Config, pub observer_timeout: Option<Duration>,
                     pub worker_jobs: u64, pub sample_interval: Duration, pub tool_slip: String, pub tool_kiln: String }
pub struct Summary { pub run: RunRecord, pub run_path: PathBuf, pub statuses: [u64; 4] /* by shard Status */, pub ends: [u64; 5] /* by End */ }
pub enum PoolError { Store(StoreError), Io(io::Error), Cancelled }
pub fn run(store: &Store, plan_id: &Digest, observers: &[Observer], phase: Phase, round: u64,
           worker: &WorkerCommand, options: &Options, tokens: &jobserver::Pool, sampler: &dyn process::Sampler)
           -> Result<Summary, PoolError>;
```

`admission` is a state machine the tests drive directly with numbers, so
every sentence of §6 has a test with no process and no sleep. `pool::run`
owns the loop: it starts workers (their stderr to the attempt's log file,
removed unless the attempt failed), speaks the protocol, feeds samples to
`Admission` and acts on its decisions, applies §5.4 including the shard the
coordinator writes on a worker's behalf, writes the run record at the end
and on cancellation, and never blocks without a way to notice a finished
child, a granted token or a cancellation. Every observer given ends with a
shard unless the run was cancelled (§1 principle 5).

Adjust shapes where needed and record the final interface in
`spec/landed/exec/WP-009.md`.

## Tests

`crates/slip_exec/tests/admission.rs` (§6): the budget formula; both
estimate sources; reservation as the larger of estimate and sample;
admission when it fits, when nothing is running, backfill of a smaller job,
the 64-skip guard; caps; pressure (newest job killed, requeued at the head
with twice its last sample, not an attempt, alone after three); cap retry
alone, and failure when already alone; budget 0.

`crates/slip_exec/tests/pool.rs` (§5–§7) with `slip-fake-worker` and a fake
sampler: every row of §5.4 (`ok`, `fail:`, `panic`, `exit:`, `abort`,
`garbage`, `wrong-observer`, `no-shard`, `hang` with a short timeout), the
retry of a crash and its two `Job` records, logs kept only for failed
attempts, `-j` never exceeded, tokens returned (a fifo made by the test has
all its tokens back afterwards) on success, failure and cancellation, plan
order, a run record that validates and whose jobs account for every
attempt, `worker_jobs` above 1, and `SIGINT`/`SIGTERM` delivered to a child
process that runs the pool (it dies by the signal, its workers are gone,
the tokens are back, the lock and `tmp/` are clean, a run record with
`cancelled` jobs exists). Tests are bounded in time and never sleep to
synchronise.
