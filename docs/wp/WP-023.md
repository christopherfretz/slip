# WP-023 — slip_digest: the tables test, the generated tables and the pins

- Status: in-progress
- Milestone: M1
- Track: C
- Needs: WP-010
- Size: M
- Parallel with: WP-021, WP-022

## Scope

`spec/digest-kinds.md` is 2713 rows that say, for every variant and
stored field of Kiln's AST, whether and how it enters the digest. This
package makes the file machine-checked and makes it the only place a tag
is written down (`spec/digest.md` §13 obligations 3, 4 and 5;
digest-kinds §1 and its "Tests" section):

1. a parser of the file by the grammar of digest-kinds §1;
2. the test that compares it with Kiln's schema descriptors;
3. `crates/slip_digest/src/tables.rs`, **generated** from the file and
   checked in: every tag and decision as Rust, and the schema pins;
4. the ratchet for obligation 5 (rows against tests) while the tests are
   being written.

It writes no part of the walk. Kiln's types are reached as
`slip_kiln::kiln::{ast, snap, source}` (on `main`); nothing here parses
C++.

The prototype of the checker is `research/digest-kinds-gen/dk_check.py`
of the context repository (118 lines; it read field lists extracted from
Kiln's source with a script, where this package reads Kiln's own
descriptors). Read it for the grammar's corner cases, not as a design.

## Interface

**The parser** is test support: `crates/slip_digest/tests/tables/mod.rs`
(and files beside it), used by `tests/tables.rs`. It gives, for the whole
file, every Kiln type (path, short name, property line) with its rows
(row text split into kind prefix, member, fact; class; decision;
encoding parsed into the forms of §1.3 with `?`, `*`, `*sorted`; note),
each with its line number, and the tables of §3.1, §3.2 and §11.1
(Slip's own enumerations). A line that looks like a table row and does
not parse is an error with its line, never skipped.

**The test** `crates/slip_digest/tests/tables.rs`, one `#[test]` per
check so that a failure names what is wrong; every message is
`digest-kinds.md:<line>: <what>` or `<Kiln type>: <what>`:

- *grammar*: §1.1 to §1.4 (headings, property lines, columns, class and
  decision words, encoding forms, `-`/`unbuilt`/`as V` only where
  allowed, short names unique, tags unique within a table and as §1.4
  computes them, the `base` ranges disjoint, `enum T` and `record T`
  naming a tabled type);
- *against Kiln* (obligation 4): the descriptors of
  `kiln_snap::Schema` for `kiln_ast::ast::Ast` and for every type whose
  `pin` is `extra`. Both ways: every field and variant of every
  descriptor that §1.1 says needs a table has a row (a row of its own,
  or at least one fact or per-kind row); every row's member exists;
  every `kind` prefix is a variant of the `selector`; a descriptor kind
  that §1.1 lists as having no table has none; every `pin` value is
  right (`schema`: reached from `Ast`; `extra`: derives `Snap`, not
  reached; `none`: no descriptor) and every `pin=none` type is in "Open
  questions / Types nothing pins"; a `retired` row may name nothing;
- *generated file is current*: `src/tables.rs` equals what the generator
  gives for the file and the linked Kiln;
- *rows against tests* (obligation 5, the ratchet below).

**The generated file** `crates/slip_digest/src/tables.rs`
(`pub(crate) mod tables`, declared in `lib.rs`), written by the test
when `SLIP_BLESS=1` is set and otherwise compared (the message says how
to bless). It starts with a comment saying it is generated, from what,
and how. It holds:

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) enum Decision { In, Out, Symbolic, Demand, Unsupported }

/// One variant row: its number (§1.4; for `as V`, V's number) and decision.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) struct Row { pub tag: u32, pub decision: Decision }

/// One module per tabled enumeration, view and `consts` type, named by
/// the short name in snake case; one constant per variant row.
pub(crate) mod decl_kind {
    pub(crate) const NAMESPACE: Row = Row { tag: 258, decision: Decision::In };
    // …
    /// Only for an enumeration that has a descriptor and that this crate
    /// can name: the row of a value. Every variant listed; no `_` arm.
    pub(crate) fn row(v: &kiln::ast::decl::DeclKind) -> Row { match v { /* … */ } }
}
/// §3.1, §3.2, §11.1 likewise (`key_kind`, `name`, `property`): numbers only.

/// Obligation 3: one assertion per pinned type (per instantiation the
/// descriptors show, for a generic one).
const _: () = assert!(<kiln::ast::decl::DeclKind as Snap>::SCHEMA_HASH == 0x…);
```

A variant with fields is matched as `V { .. }` or `V(..)`; that is not a
wildcard over variants. Where a pinned type cannot be named from outside
Kiln (a private type, a private module path), there is no `row` function
and no compile-time assertion: the test compares the hash that
`Schema::hashes()` reports with a value recorded in
`crates/slip_digest/tests/tables/pins.txt` (blessed the same way), and
the handback lists those types: each is a visibility request to Kiln.
A row function is `#[allow(dead_code)]` until the walk uses it; the
allowance is in the generated header, once.

The field rows (flags, per-kind words, records) are not generated as
code: the walk writes them by hand, in table order, and the must-differ
tests hold them to it. What the generator does give for them is a
constant list per record, `pub(crate) const ROWS: &[(&str, Decision)]`,
in table order, for the walk's own tests and for the ratchet.

**The ratchet.** `crates/slip_digest/tests/tables/untested.txt`: test
names (`<short name>/<row>`, §1.5), one per line, sorted, a `#` comment
allowed at the top only. The test fails when: a row obliges a directory
(§1.5: by decision, class and `unbuilt`) that does not exist and is not
listed; a listed name has its directory; a listed name is no row's, or
obliges nothing; a directory under `tests/differ/`, `equal/`, `demand/`
or `indeterminate/` is named by no row. A directory counts when it
holds at least one file. The list is written in full by this package
(with `SLIP_BLESS=1` the test removes names whose directory now exists
and never adds one: a new row arrives with its test or with a line
added by hand). M1 does not close with a line in it.

## Tests

Besides the checks above, which run on the real file, unit tests of the
parser and of each check on small tables written in the test (so that
each check is seen to fail): a row for a field that does not exist; a
field without a row; a per-kind row whose kind is not a variant of the
selector; a duplicate short name; a tag out of step with §1.4; `as V`
naming no variant; `enum T` naming no table; an `in` row with `-`; an
`out` row with an encoding; a `retired` row; a fact row covering a
field; a wrong `pin`. And for the generator: the output for a small
table, as a golden in the test.

`cargo test -p slip_digest --test tables` must take well under ten
seconds once built.

## Done when

`cargo xtask ci` (the full gate) passes with the real file; the handback
says how many types, rows, pins by kind (`schema`, `extra`, `none`,
recorded in `pins.txt`) and names in `untested.txt`; **every
disagreement between the file and Kiln that the test found is listed in
the handback with its line, and is fixed in `spec/digest-kinds.md` in
this package only when the fix is mechanical** (a `pin` value, a
misspelt member, a row for a field with an obvious twin). A row whose
decision has to be made (a field with no row) is not decided here: give
it the decision `unsupported` with the note `undecided (WP-023)` so that
the walk is safe, list it, and the supervisor decides. `scheme` does not
change (nothing is implemented yet).

## Out of scope

The walk. The tests the rows name. Kiln at any revision but the pin
(`kiln/` of the worktree); when the pin moves, this test is what says
which tables to review.
