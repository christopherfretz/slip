## Scope

Can start at Slip's present Kiln revision: it reads only the source
manager.

`spec/api.md` §1 (unit order) and §5.4. Two functions over Kiln's
`SourceManager` that everything with a range depends on, and that must be
right before anything edits text:

1. **The file range of a token span, or none.** Given the location of a
   first token and of a last token, return the bytes of one file that
   translation turns into exactly those tokens (tier 0), or the bytes of
   one macro argument that one use of the argument turned into them
   (tier 1), or nothing. Prior art for the rule is clang's
   `Lexer::makeFileCharRange`; Kiln's fix-it code has a version
   (`kiln_sema/src/macro_fixit.rs`). The primitives are
   `expansion_info`, `immediate_macro_caller_loc`, `entry_bounds`,
   `spelling_loc` (`kiln-landed-2026-11.md` §5).
2. **Unit order.** A comparator of two locations by their position in the
   preprocessed token sequence: walk expansion and inclusion parents to a
   common ancestor (`include_loc`, `expansion_info`).

The end of the last token is found by lexing one token of file text at
its spelling location; Kiln's `Sema::token_end_of` is not available after
the unit is built. If the token cannot be re-lexed exactly (a token made
by `##`), the answer is none.

## Interface

```rust
// crates/slip_kiln/src/ranges.rs
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum Tier { File = 0, MacroArgument = 1 }
pub struct FileRange { pub file: kiln::source::FileId, pub lo: u32, pub hi: u32, pub tier: Tier }

/// `first` and `last` are the locations of the first and the last token.
pub fn file_range(sm: &SourceManager, first: Loc, last: Loc) -> Option<FileRange>;
/// For a span that already ends at the end of its last token (a written reference's `range`).
pub fn file_range_of_span(sm: &SourceManager, span: Span) -> Option<FileRange>;
pub fn unit_order(sm: &SourceManager, a: Loc, b: Loc) -> std::cmp::Ordering;
```

## Tests

`crates/slip_kiln/tests/ranges.rs`, snippets with marked positions:

1. Tier 0: plain text; a span holding a whole object-like and a whole
   function-like invocation; a span that is exactly one invocation.
2. Tier 1: inside one argument; the same argument used twice gives the
   same range for both uses; nested invocations (an argument passed on to
   another macro).
3. None: first token in a replacement list; last token in one; a span
   that starts in file text and ends in an expansion; tokens from two
   different arguments; a pasted token; a stringised argument; a span
   across two files.
4. **The property that defines correctness**: for every `Some(r)`,
   re-preprocessing a copy of the file in which the bytes of `r` are
   replaced by a unique marker token moves exactly the span's tokens and
   no other. Run it over every expression of every snippet of the digest
   pair tests.
5. `unit_order`: tokens in a header before and after a nested include;
   tokens of one expansion; an argument used twice (two positions); it is
   a total order on the locations of a unit (sort and check adjacent
   pairs).

## Done when

The tests pass. Over three LLVM units, the property of test 4 holds for
every call expression (run once by hand, numbers in the hand-back).
