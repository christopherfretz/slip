## Scope

`spec/verify.md` §6.1 "Traces", "The site of a difference", "Other
findings", and its "Interface". Outside the trusted base in what it
*says* (no verdict depends on a place), inside it in what it *touches*:
the walk's files. The rule that governs every line: **tracing changes no
digest.**

1. **`slip_digest::trace`** (new file): `Mark`, `RefAt`, `Trace`,
   `Traced`, `trace`. The walk runs as it does today
   (`walk::run_with`); afterwards each wanted unit's stream is written a
   second time into a stream that records marks and the offsets of its
   digest fields, and is a trace only if it hashes to the unit's digest.
2. **The recorder**, in `stream.rs`: a `Stream` that is being traced
   keeps a list of marks and of the offsets of its `digest` fields; one
   that is not (every stream of the ordinary walk, and every sub-stream
   of a traced one) does nothing and allocates nothing.
3. **Two hooks**, one line each: where the expression walk begins a
   node (`crates/slip_digest/src/expr.rs:279`, the `Item::Node` arm of
   `walk_items`), and where the statement walk begins one (the
   corresponding place of WP-034's `stmt.rs`). A hook asks the stream
   whether it is traced and, if so, gives it the node's kind name and
   location.
4. **`slip_cli::locate`, complete**: `take` uses `trace`; `fill` makes
   `location` for every kind of finding as §6.1 says, with the first
   differing offset, the last mark at or before it, `refers to <name>`,
   the cause text of an indeterminate unit, and
   `verify.traces.unstable`.
5. Tests (below).

## Interface

`spec/verify.md` §6.1 "Interface". `locate`'s four items keep the
signatures WP-052 landed; `Side` gains what it needs privately.

What you build on:

- `walk::run_with` (WP-055): the walk's context and its written units
  after the ordinary pipeline, so that `Traced.output` is `digest`'s
  output by construction.
- A unit's stream is written by the first lines of `units::write`
  (`crates/slip_digest/src/units.rs:461-476`): the declaration it is
  read from (`canonical_decl` for an entity that only instantiations
  declare outside their class, else `read_decl`), the unit's state put
  aside (`take_unit`), `decl_stream`, `finish(UNIT_TAG)`. The second
  writing repeats exactly those with a traced stream; `Written.read`
  (`units.rs:35`) already holds the declaration the first writing read.
  A content-keyed unit (`content_hash`) and the order unit
  (`units::order_unit`, `units.rs:570`, whose stream is
  `order::write`'s) get the first mark only.
- The first mark's location is that of the unit's first declaration; a
  node's location is its `SourceLocation` taken to the outermost
  expansion and to a presumed line, with the subject path of its file
  from `Input.subject_path` (as `Walk::file_of` does for a group,
  `units.rs:750`).
- A node's kind name is the variant's name: Kiln's `ExprKind`
  (`kiln/crates/kiln_ast/src/expr.rs:31`) and `StmtKind`
  (`kiln_ast/src/stmt.rs:17`) derive `Debug`; use that, not a table of
  your own.
- A `RefAt` is found afterwards, not by a hook in `refs.rs`: a recorded
  digest field whose 32 bytes are the key of a unit of the image.

## Tests

- `crates/slip_digest/tests/trace.rs`: `spec/verify.md` "Tests". The two
  global properties run over every directory of the pair tests
  (`tests/equal`, `tests/differ`, `tests/demand`, `tests/indeterminate`,
  both sides): (1) `trace(input, options, all keys).output ==
  digest(input, options)`; (2) every unit that is not indeterminate has
  a trace whose stream hashes to its digest. A unit that fails (2) is a
  finding about the walk: list it in the handback with the pair's name;
  do not exclude the pair silently. If the list is not empty the test
  holds it as an explicit allow list with the reason per entry.
- For every pair of `tests/differ` whose `expect.txt` has a `changed`
  line and whose two sides have a unit of that key with different
  digests: the two traces differ at an offset, and the site on each side
  has a location in the pair's file. A pair's sides are the branches of
  one `#ifdef B` (`tests/differ/Access/Private/t.cpp`), so where the
  difference is an expression or a statement the site of side A must be
  on a line of the `#else` branch and that of side B on a line of the
  `#ifdef` branch; the test finds the branches by text, asserts it for
  the pairs under the expression and statement tables, and prints for
  all pairs how many sites it placed inside the right branch and how
  many it did not.
- `crates/slip_cli/tests/locate.rs`: `spec/verify.md` "Tests", through
  the task of WP-052 on trees the test writes: each planted difference
  (a callee, a literal, a declaration's type, a default argument, a
  removed function, an added one, an indeterminate unit) at its line.
