## Interface

The request's §3, in the form Kiln's review left it:

```rust
// kiln_lex
pub fn token_at(sm: &SourceManager, at: Loc, opts: &LexOptions) -> Option<Span>;
// kiln_source
pub struct FileRange { pub file: FileId, pub lo: u32, pub hi: u32 }
pub enum Origin { File, Argument { invocation: Span }, Body { invocation: Span },
                  Scratch { invocation: Span }, NotAFile }
impl SourceManager {
    pub fn origin(&self, at: Loc) -> Origin;
    pub fn file_char_range(&self, lo: Loc, hi: Loc) -> Option<FileRange>;
    pub fn original_offset(&self, file: FileId, offset: u32) -> Option<u64>;
}
// kiln_driver::front_end (K-b)
pub struct FrontEndOptions { /* … */ pub written_refs: bool }   // default false
```

For `Body`, Slip also needs where the token is written in the macro's
definition: that is the token's spelling location, which Kiln has
(`SourceManager::spelling_loc` or its name at the pinned commit; cite it
in the handback). No new function is asked for it.
