- Size: L

## Scope

`spec/api.md` §4 to §7 and §10, tested the way an author meets them:
through `<slip/meta.h>`, in the format of WP-090. The packages before
this one test the host in Rust; this one is the suite a second
implementation of Slip would have to pass, so it uses nothing but the
specification.

Rules:

1. At least one directory per numbered rule of §4, §5, §6.1 to §6.7 and
   §7.1 to §7.7. The directory's name is the section and rule
   (`lookup/r3-inline-namespace`).
2. A test's transform reports what it observed (`report(note, ...)` of a
   string it builds) and the expectation is the rendering; a test does
   not use `static_assert` on host results, which would make a wrong
   host a compile error with no diagnosis.
3. A rule the host cannot meet yet is an `xfail` with the reason, not an
   absent test.
4. Where the specification is silent or the host and the text disagree,
   stop: list it in the hand-back. Do not bless the host's behaviour
   into `expect.txt`.

This package may be split by the supervisor into two briefs along the
directory list (queries; effects and examples); the files do not
overlap.

transforms that complete, each run N times against its subject in two

command line: equal outputs and equal step counts; a run that fails
between two that complete changes neither.

`resource/examples/` are byte-identical to the transforms the
`examples/` directories use (they include them).

## Handback

### First brief: the queries

Directories `errors/`, `lookup/`, `structure/`, `references/`, `ranges/`
and `calls/` under `crates/slip_script/tests/api/`: 74 directories (68
compiles), 72 pass and 2 are xfails. Per section: §4 12, §5.4 7, §5.5 4,
§6.1 14, §6.2 4, §6.3 2, §6.4 4, §6.5 12, §6.6 7, §6.7 8. They add about
95 s of wall time (about 2 minutes of CPU) to
`cargo test -p slip_script --test api` in a debug build.

- **The table** of rules to directories is in
  `spec/landed/api/WP-091-queries.md`, made by `cargo xtask api-table`
  (`xtask/src/api_table.rs`, new) from the `// spec:` and `// xfail:`
  lines. The unit test `api_table::tests::the_landed_tables_are_current`
  fails when a generated block in `spec/landed/` no longer matches.
- **The xfails**: `calls/r8-every-call-is-returned-or-counted` (the host
  has no counter `api.calls_without_reference`; §6.7 rule 8 names it and
  §7.6 rule 6 does not) and `ranges/s5.4-no-directive-argument-in-group`
  (an argument inside one group of a conditional gets a null extent, by
  `spec/landed/api/WP-086.md` decision 9, where §5.4 says it is a range).
- **Rules with no directory**, none observable through queries: §4 rule
  4, §5.4 rules 4 and 7, §6.5 rule 5.
- **Silences in the text**: eleven, listed in the landed file with their
  subjects; none was blessed.
- **Items for Kiln**: none.
- **Tooling changes outside the suite**: the `landed` lint accepts
  `spec/landed/<spec>/WP-NNN-<part>.md` for one brief of a split package
  (the name this brief was given), with `spec/harness.md` §3 and
  `xtask/tests/lint.rs` `s3_landed` updated; three helpers of
  `xtask/src/lint/api_tests.rs` became `pub(crate)` for the table.
