## Scope

The second build of the design ruled in `docs/wp/WP-141.md`
(`spec/landed/digest/WP-141.md`, option 5, §8.1 "Named whole", §8.2,
§8.4, §8.5). WP-141 writes a using-directive at namespace scope and a
namespace alias in an owned file with the reading of the namespace's
own key, so in the migration of a root namespace into one a dependency
opens the correctly redirected `using namespace legacy;` →
`using namespace acme;` is still `removed` and `added`, and the split
directive of WP-141's central case is `added`. This package makes them
verify:

1. **The design is attacked before it is built** (the supervisor
   commissions it; its findings are appended here before the status
   leaves `todo`). The comparison stops being plain equality of
   multisets for the groups that have an alternate, and the fast path
   of `spec/verify.md` §4.1 gains a second digest. Both are the trusted
   base's innermost step.
2. **Alternates in the digest** (`spec/digest.md` §3.4, §11): each
   other reading of an owned whole-namespace reference that is whole is
   an alternate of its unit (the key and digest the unit would have
   with that reading, and the unit's group); the `digests` section
   carries the alternates, the alternate sum of each group that has
   one, and `tu_alt`; present only for an image digested under a table
   that gives some namespace a second view key.
3. **Step 1a** of `spec/verify.md` §4 and the two additions to §4.1, as
   §8.2 of the proposal states them, with the exactness argument for
   the restriction to `G` written in the spec and tested (a group with
   equal sums; a group whose alternate sum equals the pre-image's; a
   mixed group, which needs the unit lists).
4. **The rows**: D1, A1, C1, C4, C5, C7, V1, V2 of the proposal's §6
   turn to no finding; C6, C8, C2, C3, A4, A5, D3, D4, T5, T6 keep the
   answers WP-141 left; WP-140's `directive-redirected` and
   `alias-redirected` turn over; pitfall rows `good` D1, A1 and C1 in
   `O0`, `O1` and `O2`. `expect.txt` names each alternate taken.
5. **The report**: an informational line per rule with the number of
   owned references that name a namespace with a part the pre-image's
   reference did not name (the surplus, T1 and T2 of the proposal), and
   the sentence of `spec/verify.md` §8 that says what is not shown.
