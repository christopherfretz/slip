## Scope

In the crate `slip_exec`:

1. **Protocol 2** (`spec/exec.md` §5.2, §5.6 "Messages", §5.7): `Job`
   gains `transform` and `post`; `Post`, `PostImage`; `PROTOCOL` is 2;
   `pool::run_with` and `JobExtra`. This is the one change of the
   protocol for M1's verify command and for M2 together: M1's verify job
   (`docs/wp/WP-052.md`, `docs/wp/WP-053.md`) gets its parameters from
   `Job.post` with a `tree` image, M2's from the same field with an
   `overlay` image. **This package owns `Job`, `Post` and the protocol
   number; no other package changes them.**
2. **The store** (`spec/edits.md` §10.4, `spec/exec.md` §2): the files of
   a transform, blobs, the next round, the transform run record, the
   journal's refusal.

`slip_exec` deals in bytes and digests: it does not decode the new
containers beyond reading a content id (`formats::content_id`), so it
needs none of the types of `docs/wp/WP-060.md`.

Files: `crates/slip_exec/src/store.rs`, `src/worker.rs`, `src/pool.rs`
(where a `Job` is built, and `run_with`), `src/bin/slip-fake-worker.rs`,
new `crates/slip_exec/tests/objects.rs`; the existing `tests/worker.rs`
and `tests/pool.rs` where the protocol number shows; every place of the
workspace that builds a `Job` literal (two `None`s each).

**Starts now.** `docs/wp/WP-050.md` (the map task) is being implemented
and builds `Job`s in its tests: merge `origin/main` before handing back
and give every `Job` literal that is new there its two fields.
`declared/` and `Store::{declared_path, publish_declared, read_declared}`
are M1's (`spec/exec.md` §2.2, `docs/wp/WP-052.md`), not this package's.

## Interface

`spec/exec.md` §5.7 for `slip_exec::worker` and `slip_exec::pool`,
exactly:

```rust
// slip_exec::worker
pub const PROTOCOL: u64 = 2;
pub struct Job { /* … */ pub transform: Option<Digest>, pub post: Option<Post> }
pub struct Post { pub pre: u64, pub declared: Digest, pub image: PostImage }
pub enum PostImage { Tree(Vec<(Vec<u8>, Vec<u8>)>), Overlay(Digest) }   // (subject, post), ascending

// slip_exec::pool
pub struct JobExtra { pub transform: Option<Digest>, pub post: Option<Post> }
pub fn run_with(store: &Store, plan_id: &Digest, observers: &[Observer], phase: Phase, round: u64, extra: &JobExtra,
                worker: &WorkerCommand, options: &Options, tokens: &jobserver::Pool, sampler: &dyn process::Sampler)
                -> Result<Summary, PoolError>;
// `run` keeps its signature and is `run_with` with neither field.
```

and for the store:

```rust
// slip_exec::store
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Object { Transform, EditSet, Overlay, Result }
impl Object {
    pub fn dir(self) -> &'static str;        // "transforms", "edits", "overlays", "results"
    pub fn extension(self) -> &'static str;  // "trfm", "edts", "ovly", "rslt"
    pub fn kind(self) -> [u8; 4];
}
impl Store {
    /// Publishes a container of `object`'s kind under its content id.
    /// `Invalid` if `bytes` is not a container of that kind.
    pub fn publish_object(&self, object: Object, bytes: &[u8]) -> Result<Digest, StoreError>;
    pub fn read_object(&self, object: Object, id: &Digest) -> Result<Option<Vec<u8>>, StoreError>;
    pub fn find_object(&self, object: Object, hex_prefix: &str) -> Result<Vec<Digest>, StoreError>;
    pub fn object_path(&self, object: Object, id: &Digest) -> PathBuf;

    /// A file's bytes under their content digest (`spec/model.md` §6).
    pub fn publish_blob(&self, bytes: &[u8]) -> Result<Digest, StoreError>;
    /// `Invalid` if the bytes do not hash to `id`.
    pub fn read_blob(&self, id: &Digest) -> Result<Option<Vec<u8>>, StoreError>;
    pub fn blob_path(&self, id: &Digest) -> PathBuf;

    /// spec/edits.md §8, spec/exec.md §2: the least round for which the
    /// plan has neither `map.<r>` nor `verify.<r>` among its shard
    /// directories and no `transform.<r>.*.run` among its run records.
    pub fn next_round(&self, plan: &Digest) -> Result<u64, StoreError>;
    /// Whether a transform's run took the round (it has a transform run record).
    pub fn is_transform_round(&self, plan: &Digest, round: u64) -> Result<bool, StoreError>;
    pub fn publish_transform_run(&self, plan: &Digest, round: u64, started_unix_ns: u64, bytes: &[u8])
        -> Result<PathBuf, StoreError>;

    pub fn journal_path(&self) -> PathBuf;
    /// Opens a store that has a journal; the only way to (`apply --recover`).
    pub fn open_for_recovery(dir: &Path) -> Result<Store, StoreError>;
}
// StoreError gains `UnfinishedWrite(PathBuf)`: what `Store::open(_, Access::Exclusive)`
// returns when `write.journal` exists. `Access::Shared` (a worker) is not refused.
```

- Everything is published as `spec/exec.md` §2.1 publishes: a temporary
  entry, renamed; publishing content that is already there is not an
  error and leaves the file untouched. The directories are made by the
  first publish into each (a store initialised before them is a valid
  store).
- `pool::run_with` rejects (`Invalid`), before any worker is started,
  `transform` with phase `verify`, `post` with phase `map`, and phase
  `verify` without `post`. The task refuses the same three (`spec/exec.md`
  §5.2); the coordinator's check is what a caller sees first.
- A worker whose `Ready.protocol` is not `PROTOCOL` is a protocol
  violation (`spec/exec.md` §5.6 "Messages").
- `latest_run` (`spec/exec.md` §2.1) must not take a transform run
  record for a phase's: the names differ in their first component, and a
  test says so.
- `slip-fake-worker` answers protocol 2 and echoes what the job carried
  into counters of its shard, so that `tests/pool.rs` can see the fields
  arrive.

## Tests

`crates/slip_exec/tests/objects.rs`: each object kind published, read,
found by prefix (none, one, two matches); a container of another kind
refused; a blob read back; a blob file whose bytes were changed on disk
is refused; `next_round` with no directory, with `map.0` only, with
`map.0` and `verify.1`, with a transform run record of round 2 and no
shard directory; `is_transform_round`; `latest_run` beside a transform
run record; the journal: exclusive open refused, shared open allowed,
`open_for_recovery` allowed; a transform run record's path.
`tests/worker.rs`: `Job` with each combination of the two fields and
each form of image round trips; `RootMap`s out of order are refused by
the decoder. `tests/pool.rs`: the fields reach the worker; each of the
three rejected combinations; a worker that says protocol 1 is treated as
crashed.
