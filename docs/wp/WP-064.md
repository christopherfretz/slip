## Scope

`spec/edits.md` §10.3 and §10.4, with the paragraphs they added to
`spec/exec.md` §2 and §5.2, in the crate `slip_exec`. The store learns to
hold a transform's files, and a job learns to carry a transform or a
post-image. `slip_exec` deals in bytes and digests: it does not decode
the new containers beyond reading a content id (`formats::content_id`,
`crates/slip_model/src/formats/mod.rs:401`), so it needs none of WP-060's
types.

Files: `crates/slip_exec/src/store.rs`, `src/worker.rs`, `src/pool.rs`
(only where a `Job` is built), `src/bin/slip-fake-worker.rs`, new
`crates/slip_exec/tests/objects.rs`; the existing `tests/worker.rs` and
`tests/pool.rs` where the protocol number shows.

**Order with M1.** M1's verify job is being specified in parallel and may
change `Job` and the protocol number itself. If it has landed, this
package's two fields go after its fields and the protocol number is one
more than what is on `main`; if it has not, the supervisor says which of
the two goes first. Either way the result is one `Job` record with the
fields of both, and `spec/exec.md` §5.2 says so; record what was done in
the handback.

## Interface

```rust
// slip_exec::store
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Object { Transform, EditSet, Declared, Overlay, Result }
impl Object {
    pub fn dir(self) -> &'static str;        // "transforms", "edits", "declared", "overlays", "results"
    pub fn extension(self) -> &'static str;  // "trfm", "edts", "decl", "ovly", "rslt"
    pub fn kind(self) -> [u8; 4];
}
impl Store {
    /// Publishes a container of `object`'s kind under its content id.
    /// `Input` if `bytes` is not a container of that kind.
    pub fn publish_object(&self, object: Object, bytes: &[u8]) -> Result<Digest>;
    pub fn read_object(&self, object: Object, id: &Digest) -> Result<Option<Vec<u8>>>;
    pub fn find_object(&self, object: Object, hex_prefix: &str) -> Result<Vec<Digest>>;
    pub fn object_path(&self, object: Object, id: &Digest) -> PathBuf;

    /// A file's bytes under their content digest (`spec/model.md` §6).
    pub fn publish_blob(&self, bytes: &[u8]) -> Result<Digest>;
    /// `Input` if the bytes do not hash to `id`.
    pub fn read_blob(&self, id: &Digest) -> Result<Option<Vec<u8>>>;
    pub fn blob_path(&self, id: &Digest) -> PathBuf;

    /// spec/edits.md §8: the least round with neither `map.<r>` nor
    /// `verify.<r>` under the plan's shard directory.
    pub fn next_round(&self, plan: &Digest) -> Result<u64>;
    pub fn publish_transform_run(&self, plan: &Digest, round: u64, started_unix_ns: u64, bytes: &[u8])
        -> Result<PathBuf>;

    pub fn journal_path(&self) -> PathBuf;
    /// Opens a store that has a journal; the only way to (`apply --recover`).
    pub fn open_for_recovery(dir: &Path) -> Result<Store>;
}
// StoreError gains `UnfinishedWrite(PathBuf)`: what `Store::open(_, Access::Exclusive)`
// returns when `write.journal` exists. `Access::Shared` (a worker) is not refused.

// slip_exec::worker
pub struct Post { pub overlay: Digest, pub declared: Digest }
pub struct Job { /* … */ pub transform: Option<Digest>, pub post: Option<Post> }
pub const PROTOCOL: u64 = 2;

// slip_exec::pool::Options gains
pub transform: Option<Digest>,     // every job of a map phase carries it
pub post: Option<Post>,            // every job of a verify phase carries it
```

- Everything is published as `spec/exec.md` §2.1 publishes: a temporary
  entry, synced, renamed; publishing content that is already there is not
  an error and leaves the file untouched.
- `pool::run` rejects (`Input`) `transform` with phase `verify` and `post`
  with phase `map`. A worker whose `Ready.protocol` is not `PROTOCOL` is a
  protocol violation (`spec/exec.md` §5.6 "Messages" gains the row).
- `slip-fake-worker` answers protocol 2 and echoes what the job carried
  into a counter of its shard, so that `tests/pool.rs` can see the fields
  arrive.

## Tests

`crates/slip_exec/tests/objects.rs`: each object kind published, read,
found by prefix (none, one, two matches); a container of another kind
refused; a blob read back; a blob file whose bytes were changed on disk
is an `Input` error; `next_round` with no directory, with `map.0` only,
with `map.0` and `verify.1`; the journal: exclusive open refused, shared
open allowed, `open_for_recovery` allowed; a transform run record's path.
`tests/worker.rs`: `Job` with each combination of the two fields round
trips; a job of protocol 1's shape (neither field) still decodes.
`tests/pool.rs`: the fields reach the worker; a worker that says
protocol 1 is treated as crashed.
