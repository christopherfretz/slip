## Scope

Slip's pin is the head of Kiln's branch `slip/kf1` (`62d190007`), which
has the front-end entry (`kiln_driver/src/front_end.rs`) and not the
written-reference table; Kiln's `main` (`0295475a3` when this was
written) has the table (Kiln WP-1930, WP-1931) and the fixes for the 19
units of the `llvm` corpus that fail at the pin, and not the entry. A
rename needs both. This package moves the pin to one commit that has
both and absorbs what changed in between.

**Needs from Kiln, before it starts:** the entry landed on `main`, or a
commit Kiln names that contains `slip/kf1` and `main`. Slip does not
merge or rebase Kiln branches itself. The supervisor gives the commit.

**If M1's plan already has a pin move** (it needs the same fixes to close
the corpus), this package is that one: do not do it twice. The supervisor
drops whichever is the duplicate.

Work:

1. Move the submodule `kiln` to the commit. Make `slip_kiln` compile
   against it; every change is in `crates/slip_kiln/` and is listed in
   the handback with the Kiln change that caused it.
2. Run the tables test (`crates/slip_digest/tests/tables.rs`), which
   compares `spec/digest-kinds.md` with Kiln's AST. **This package does
   not edit `spec/digest-kinds.md` or `crates/slip_digest/src/`.** If the
   test fails, the package hands back its branch with the list of
   differences (the row, Kiln's `file:line` at the old and at the new
   commit, and whether the difference is a renumbering, a new field or
   kind, or a removal). The table corrections are a package of track C on
   top of this branch, with the trusted base's review; this one resumes
   when it has landed.
3. Run every pair test and the determinism test of `slip_digest`. A
   digest that changed for a source that did not is reported the same
   way.
4. Parse the `llvm` corpus (`cargo xtask corpus` as `spec/harness.md` §8
   says, through the jobserver, in the background): the outcome counts
   and the baseline under `bench/` are updated with the reason. Expected:
   no unit `failed`, two `diagnosed` (`spec/harness.md` §8.7).
5. `spec/harness.md` §8.7 and `README.md`, wherever the pin or the 19
   failures are stated.

Files: the submodule pointer, `crates/slip_kiln/`, `bench/` baselines,
the two documents. This package can start before M1 closes, but it moves
the ground under every open package of `slip_digest`: the supervisor
picks the moment.
