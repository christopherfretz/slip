## Scope

`crates/slip_model/src/json.rs`, implementing `spec/model.md` §4. The module
file exists as a stub; `lib.rs` already declares it. Kiln has a
dependency-free JSON module you may read for ideas
(`kiln/xtask/src/util/json.rs`); this one is stricter and its value model
differs, so write it against the spec.

## Interface

```rust
pub enum Value { Null, Bool(bool), Int(i128), Float(f64), Str(String), Array(Vec<Value>), Object(Vec<(String, Value)>) }
//   Int holds −2^63..2^64 only; the reader never produces a value outside it.
pub struct Error { pub offset: usize, pub line: usize, pub column: usize, pub message: String }   // Display + std::error::Error
pub fn parse(bytes: &[u8]) -> Result<Value, Error>;
pub fn write_compact(value: &Value) -> Result<String, WriteError>;
pub fn write_pretty(value: &Value) -> Result<String, WriteError>;     // errors only for a non-finite Float or an out-of-range Int
impl Value { /* get(&str) for objects, as_str, as_array, as_object, as_u64, as_i64, as_bool */ }
```

## Tests

`crates/slip_model/tests/json.rs`, each naming the sentence of §4 it covers:
every value kind; each rejection the reader must make (one test per item in
the list), with the offset; `Int`/`Float` classification at the boundaries
(−2^63, 2^64−1, 2^64, `1.0`, `1e3`, `-0`); surrogate pairs; the byte-order
mark; both writer forms, exactly (including empty containers and every
string escape); `parse(write(v)) == v` over a table of values; key order
preserved.

## Done when

The tests pass; clippy with `-D warnings` and `cargo fmt --all --check` are
clean; no dependency was added.

## Out of scope

Everything else in `slip_model`. Streaming input. Comments or any other
extension to JSON.
