# WP-080 — slip_kiln: a transform session (compile once, run many)

- Status: review
- Milestone: M3
- Track: B
- Needs: WP-025
- Size: M
- Parallel with: WP-081..088

## Scope

Launch after Slip's Kiln revision is on Kiln main (Kiln WP-2120 with
WP-1990 and WP-1995). `docs/design/notes/kiln-landed-2026-11.md` §3 and
§4 give the Kiln interface with places; read them against the pin first.

`spec/api.md` §2.1 (the command line), §2.2 (the files read), §2.4 rule 5,
§2.5. A facade in `slip_kiln` over Kiln's `with_eval_session`,
`EvalSession`, `RunBudget`, `CancelToken` and `HostCalls`, so that
`slip_script` names no Kiln crate (lint `kiln-boundary`). This package
knows nothing of the API's operations: a handler here is any
`FnMut(op, ints, bytes, out)`.

The first task is a finding, not code: does a handler that borrows
`&kiln::ast::Ast` satisfy `HostCalls: Send`
(`kiln-landed-2026-11.md` §3.4 item 1)? Write the compile test. If it
fails, stop and hand back: `docs/requests/KS1-amendment-1.md` is then on
the critical path and is sent.

## Interface

```rust
// crates/slip_kiln/src/session.rs

/// The command line of spec/api.md §2.1, already checked (rule 2).
pub struct TransformCommand { pub resource_include: PathBuf, pub author: Vec<String>, pub file: PathBuf }

pub enum CompileError {
    /// spec/api.md `transform-compile`; the diagnostics as Kiln renders them.
    Diagnosed { rendered: String, errors: u32 },
    /// Kiln refused the command line Slip built: a Slip bug.
    CommandLine(String),
    Panicked(String),
}

/// One file the transform unit read: path as given, content digest.
pub struct ReadFile { pub path: Vec<u8>, pub digest: slip_model::Digest }

pub struct Budget { pub steps: u64, pub bytes: u64, pub depth: u32 }

/// What a handler writes into (Kiln's `HostOut`, without its type).
pub trait Out {
    fn int_capacity(&self) -> usize;
    fn byte_capacity(&self) -> usize;
    fn write_ints(&mut self, v: &[u64]);
    fn write_bytes(&mut self, v: &[u8]);
}

/// `Err(text)` is Kiln's uncatchable handler error (spec/api.md §3.5 rule 4).
pub trait Handler { fn call(&mut self, op: u32, ints: &[u64], bytes: &[u8], out: &mut dyn Out) -> Result<u64, String>; }

pub enum EntryError { Missing, Overloaded, NotFunction, NotConsteval, Parameters, Type, Undefined }
pub enum RunFailure { NotConstant, StepBudget, MemoryBudget, DepthLimit, Cancelled, Host(String), Uncaught { type_name: String } }
pub struct RunReport { pub result: Result<(), RunFailure>, pub steps: u64, pub host_calls: u64, pub peak_bytes: u64, pub rendered: String }

pub struct Session<'a> { /* yours */ }
impl Session<'_> {
    pub fn files(&self) -> &[ReadFile];
    /// `Ok(true)`: a function of that name exists in the global namespace.
    pub fn declares(&mut self, name: &str) -> bool;
    pub fn entry(&mut self, name: &str) -> Result<Entry, EntryError>;   // `Type` unless it returns void
    pub fn run(&mut self, entry: Entry, handler: &mut dyn Handler, budget: Budget, cancel: &Cancel) -> RunReport;
}

/// Compiles the transform on the calling thread and calls `f` with the
/// session. The caller's thread must have the stack it wants; this
/// installs Kiln's stack guard for it.
pub fn with_transform<R>(cmd: &TransformCommand, stack: usize, f: impl FnOnce(Result<Session<'_>, CompileError>) -> R) -> R;
```

`Session::run` may be called from the thread of a subject unit's front end
(`parse_observer_with`'s closure) while `with_transform`'s thread waits:
`Session` is `Send`. Show it in a test.

## Tests

`crates/slip_kiln/tests/session.rs`:

1. A handler holding `&Ast` of a snippet compiles and runs (or the
   hand-back above).
2. Compile once, run 1000 times with a counting handler: results, steps
   and host-call counts are equal on every run.
3. A session and a subject front end alive at once, on one thread and on
   two: both give the results they give alone.
4. Each `EntryError`; `declares` for a reserved name.
5. Each `RunFailure`, with `rendered` holding the call-stack notes; the
   session runs normally afterwards.
6. `files()` lists `<slip/meta.h>`, `<slip/__intrinsics.h>` and every
   standard header read, each with the digest of the bytes on disk.
7. `__DATE__` and `__TIME__` are the epoch's.
8. An author option outside §2.1 rule 2 never reaches Kiln (it is
   refused when `TransformCommand` is built).

## Handback

**Round 1** (branch `wp/080-transform-session`). The interface is in
`crates/slip_kiln/src/session.rs`. The decisions are in
`spec/landed/api/WP-080.md`. The tests are in
`crates/slip_kiln/tests/session.rs`.

**First task: a handler that borrows `&kiln::ast::Ast` satisfies
`HostCalls: Send`.** Test `t1_handler_borrowing_ast_is_send` compiles at
Kiln `83566cc47`. `Ast` is `Sync` by auto-trait, and nothing in Kiln
asserts it. If an `Rc` is added to the handler, the test fails with E0277
at `kiln/crates/kiln_oven/src/host.rs:13`, so the check is live. KS1
amendment 1 is therefore not on the critical path. It is still wanted, to
keep `Ast: Sync` from regressing silently.

Differences from the package's interface:

- `TransformCommand` has private fields and a checked constructor
  `new(..) -> Result<_, OptionRefused>`, plus `command_line()`. With
  public fields an unchecked command could be built, and test 8 requires
  that this cannot happen.
- `Handler: Send`, which Kiln's `HostCalls: Send` forces.
- `Cancel` is defined here (`CancelToken` wrapped). The package names it
  without listing it.
- `CompileError::CommandLine` also covers a front end that stopped for
  another reason, because Kiln does not distinguish the two (KS2
  amendment 1 §1).

Every test was seen to fail with its code mutated, by mutation runs on
`session.rs`:

| Test | Mutation | Failure |
|---|---|---|
| t1 | `trait Engine` without `Send`; an `Rc` in the test handler | E0277 at compile time |
| t2 | `host_calls: 0` | `left: 0 right: 10` |
| t1/t3 | the adapter does not forward to the handler | nothing reported |
| t4 | `Undefined` before `Type`; templates not counted by `declares` | each assertion fails |
| t5 | `rendered` empty | the assertion on the notes fails |
| t6 | only the first file listed | `meta.h` missing |
| t7 | `-fkiln-reproducible-time` dropped | `Nov 22 2026` / `23:47:41` |
| t8 | an unknown word accepted | `expect_err` panics |

Follow-ups, each decided:

- **`Ast: Sync` is unasserted.** Deferred to KS1 amendment 1, which is
  already sent.
- **Uncaught exceptions have no call stack in the diagnostic**, only the
  throw location (`kiln/crates/kiln_oven/src/session.rs` `RunError::Uncaught`).
  Deferred: added to KS2 amendment 1 §3 at the next request round, and
  listed in the landed file's open questions.
- **`#embed` resources are missing from `files()`.** Deferred: open
  question 2 of the landed file, for the identity design (WP-089).
- **`declares` and `entry` see through using-directives.** Deferred: open
  question 1 of the landed file. The spec should say what it wants.
