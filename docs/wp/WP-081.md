## Scope

Can start now: it needs nothing from Kiln.

`spec/api.md` §3 (all), §4 (the status values), §5.2 (validation of
forged values), §7.6 (the run output and its canonical form), and the
query half of the table of §3.2. The host as a pure function over a
**subject** given as a trait, tested against a fake subject held in
memory. The effect operations (64 to 84) are dispatched here and
implemented in WP-088; until then they return `unsupported`. The trait
below is complete, the effects' methods included, so that no later
package changes it: the four packages that implement it over Kiln
(WP-083, WP-085, WP-086, WP-095) and the one that calls it (WP-088) run
in parallel against this text.

`resource/include/slip/__intrinsics.h` is the other half of §3: a test
reads that file and checks that every operation number and kind bit in it
equals the constant here, so the two cannot drift.

## Interface

```rust
// crates/slip_script/src/wire.rs
pub const OP_ERROR_MESSAGE: u32 = 2; /* ... one per row of spec/api.md §3.2 */
pub enum Errc { InvalidHandle = 1, WrongKind = 2, InvalidArgument = 3, NotEditable = 4, Unsupported = 5, LimitExceeded = 6 }
pub const STATUS_UNKNOWN_OP: u8 = 254;
pub const STATUS_MALFORMED: u8 = 255;

// crates/slip_script/src/subject.rs
#[derive(Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)] pub struct Entity(pub u32);
/* likewise Declaration, Reference, Expression, File */
pub struct Range { pub file: File, pub lo: u32, pub hi: u32 }
pub enum Value { Entity(Entity), Declaration(Declaration), Reference(Reference), Expression(Expression) }

/// One subject unit, as the host sees it. Every sequence is returned in
/// the order spec/api.md gives; the host does not sort.
pub trait Subject {
    fn is_live(&self, v: Value) -> bool;
    fn file_len(&self, f: File) -> Option<u32>;
    fn kind_bits(&self, v: Value) -> u64;
    fn lookup(&self, global: bool, components: &[&[u8]]) -> Vec<Entity>;
    fn identifier(&self, v: Value) -> Option<Vec<u8>>;          // None: an expression
    fn display(&self, v: Value) -> String;
    fn parent(&self, e: Entity) -> Option<Entity>;
    fn parameters(&self, v: Value) -> Option<Vec<Entity>>;      // None: wrong kind
    fn declarations(&self, e: Entity) -> Result<Vec<Declaration>, Errc>;
    fn entity_of(&self, d: Declaration) -> Entity;
    fn origin(&self, e: Entity) -> Entity;                      // spec/api.md §5.5
    fn references_to(&self, e: Entity) -> Vec<Reference>;
    fn referent(&self, r: Reference) -> Entity;
    fn name_range(&self, v: Value) -> Result<Option<Range>, Errc>;
    fn extent(&self, v: Value) -> Result<Option<Range>, Errc>;
    fn text(&self, r: Range) -> &[u8];
    fn owned(&self, f: File) -> bool;
    fn calls_to(&self, e: Entity) -> Result<Vec<Expression>, Errc>;
    fn callee(&self, x: Expression) -> Option<Entity>;          // None: not a call
    fn callee_reference(&self, x: Expression) -> Option<Reference>;
    fn arguments(&self, x: Expression) -> Option<Vec<Expression>>;

    // What the effects need (§7). WP-088 is their only caller.
    /// §5.4: 0 or 1 if `r` is a range the subject gave out or lies inside one; else None.
    fn tier(&self, r: Range) -> Option<u8>;
    /// §7.2 rule 2: the identifiers from the outermost named scope to `e`; None: §7.1 rule 4.
    fn qualified(&self, e: Entity) -> Option<Vec<Vec<u8>>>;
    /// §7.2 rule 1: the references whose extent is exactly `r`.
    fn references_at(&self, r: Range) -> Vec<Reference>;
    /// §7.2 rule 1, third condition.
    fn found_directly(&self, r: Reference) -> bool;
    /// The key of `e` as an entity (for a spelled piece); None: it has none, and `spell` refuses.
    fn entity_key(&self, e: Entity) -> Option<slip_model::Digest>;
    /// §7.5 rule 1: the key of the unit that holds `v` (a reference or an expression;
    /// the host refuses the other sorts before asking), then the keys derived from it, sorted.
    fn unit_keys(&self, v: Value) -> Result<Vec<slip_model::Digest>, Errc>;
    /// §7.5 rule 3.
    fn rename_rule(&self, e: Entity, new_identifier: &[u8]) -> Result<slip_model::keys::Rule, Errc>;
    /// §7.4 rule 3: the place, and whether it is the value's own (`false`: the nearest nameable place).
    fn place(&self, v: Value) -> Option<(Range, bool)>;
    fn file_ref(&self, f: File) -> slip_model::FileRef;
}

// crates/slip_script/src/host.rs
pub trait Out { /* the four methods of WP-080's `Out` */ }
pub struct Limits { /* spec/api.md §7.7; Default is the table */ }
pub struct Failure { pub ordinal: u64, pub op: u32, pub errc: u8, pub message: String, pub place: Option<Range> }

pub struct Host<'s> { /* yours */ }
impl<'s> Host<'s> {
    pub fn new(subject: &'s dyn Subject, transform: slip_model::Digest, limits: Limits) -> Host<'s>;
    /// One operation. `Err` only for a host-internal failure.
    pub fn call(&mut self, op: u32, ints: &[u64], bytes: &[u8], out: &mut dyn Out) -> Result<u64, String>;
    pub fn failures(&self) -> &[Failure];
    pub fn finish(self) -> output::RunOutput;
}

// crates/slip_script/src/output.rs: RunOutput, Edit, Piece, Report as in spec/api.md §7.6.
// crates/slip_script/src/fake.rs: FakeSubject, built from a small literal description.
```

`Out` is declared here so that this package has no dependency on WP-080;
WP-089 adapts one to the other.

Rules, each with a test:

1. Handles: `tag << 48 | index`; the host issues an index only for a
   value the subject says is live, remembers which it issued in this
   `Host`, and refuses every other number with `invalid_handle`.
2. Convention B writes all or nothing; the returned counts are the same
   either way.
3. A failed operation changes nothing in the host except the failure
   list.
4. `lookup` parses the grammar of §6.1 rule 1 here and passes components
   to the subject.
5. Statuses 254 and 255 for an unknown operation and for a shape that
   does not fit; never `Err`.
6. `finish` returns the canonical form: sorted, deduplicated, identity by
   content, no single-member group.
