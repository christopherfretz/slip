# WP-005 — xtask: lint, wp, ci

- Status: done
- Milestone: M0
- Track: G
- Needs: none
- Size: M
- Parallel with: WP-001, WP-002, WP-003, WP-004

## Scope

`xtask/`, implementing `spec/harness.md` §2 (steps `lint`, `fmt`, `clippy`,
`test`, `kiln`; the `transform` step exists and reports that there are no
transform tests yet), §3 with §3.1, and §4. One module per command; `main.rs`
only dispatches. xtask has no dependencies in this WP.

## Interface

The command lines of `spec/harness.md`. `cargo` is found through the `CARGO`
environment variable (set by cargo for `cargo run`), falling back to `cargo`,
so tests can substitute a fake. Lints take the repository root as a
parameter so tests can point them at fixture trees; the file list comes from
`git ls-files` in a real checkout and from walking the tree in a fixture
that is not a git repository.

## Tests

`xtask/tests/lint.rs`, `tests/ci.rs`, `tests/wp.rs` as listed in
`spec/harness.md` "Tests". Fixture trees are built by the tests in a
temporary directory they remove. Every lint has a passing fixture and a
failing one with the exact expected message.

## Done when

The tests pass; `cargo xtask lint` passes on the repository itself (fix what
it finds in files you own; report the rest in the handback instead of
editing other work packages' files); `cargo xtask ci --quick` runs the four
quick steps; clippy with `-D warnings` and `cargo fmt --all --check` are
clean.

## Out of scope

`cargo xtask jobserver` and `perf` (they need WP-004 and WP-006). Transform
tests. Any CI service configuration.
