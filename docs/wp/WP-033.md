## Tests

Per row as the common rules say. Beyond the rows:

- `equal`: reopening a namespace; two namespaces' members interleaved
  differently; `inline` on the first declaration of a namespace only.
- order unit: `differ` when two namespace-scope definitions are
  swapped (the units of the variables equal, `order` changed), when a
  declaration `extern int a;` stays and the definitions swap; `equal`
  when only declarations move, when a function is added between them,
  when a block-scope static is added; `demand`: a use that instantiates
  a static data member of a class template or a variable template
  leaves `order` equal.
- unit tests in each file for helpers.

A test whose difference is inside a child another area still writes as
its placeholder is marked `# pending` with the area; before the
handback, with `origin/main` merged, un-pend those whose area has
landed and see each pass and, for one in five, fail when the row is
broken.
