## Scope

`spec/harness.md` §6.2 (a transform test), §6.3 (`cargo xtask
transform`), §6.4 (the five oracles) and the `transform` step of the
gate (§2). The runner drives the `slip` executable from outside and
judges it by files; it knows nothing of rename.

It is written and tested **before `slip rename` exists**, against a
scripted stand-in for `slip` (as `slip_exec` tests its coordinator
against `slip-fake-worker`), so that the runner is ready the day the
commands are. The tests of rename themselves are `docs/wp/WP-078.md`.

Files: new `xtask/src/transform.rs` and `xtask/src/transform/{test_file.rs,
tree.rs, run.rs, oracles.rs, mutate.rs}`, new `xtask/tests/transform.rs`
with its fixtures under `xtask/tests/transform/`, a stand-in executable
`xtask/src/bin/fake-slip.rs`; `xtask/src/main.rs` and `xtask/src/lib.rs`
for the subcommand; `xtask/src/ci.rs` (`:160`, the `transform` step) and
`xtask/tests/ci.rs` (`:146`, `:189`, which expect today's message).
The mutation oracle writes `EDTS` containers with `slip_model`, which
`xtask` already depends on (`xtask/Cargo.toml`).

Starts when WP-061 is on `main`. Needs nothing of M1 or Kiln.

## Interface

```
cargo xtask transform [--only <substring>]… [--bless] [-j <n>] [--no-clang] [--slip <path>]
```

`--slip` names the executable (default: the workspace's `slip`, built
by the runner through `cargo build -p slip_cli` under the jobserver);
the runner's own tests pass the stand-in.

```rust
// xtask::transform
pub struct Test { /* test.txt parsed: spec, run, state, exit, std, args, tu, owned, readonly, allow
                     (residue, unparsed, partial, errors), oracle, xfail */ }
pub fn parse_test(dir: &Path) -> Result<Test, String>;       // every malformed line is an error naming the line
pub enum Outcome { Pass, Fail(String), XFail, XPass, Error(String), Skip(String) }
pub fn run_one(test: &Test, slip: &Path, work: &Path, clang: Option<&Path>, bless: bool) -> Outcome;
pub fn main(root: &Path, args: &[String]) -> ExitCode;

// xtask::transform::mutate
/// The mutated edit sets of spec/harness.md §6.4, in the order given there.
pub fn mutations(set: &EditSet) -> Vec<(String, EditSet)>;   // (a label for the message, the set)
```

Rules fixed here, beyond §6.2 to §6.4:

- **Outcomes and the gate.** `Fail`, `Error` and `XPass` fail the gate;
  `XFail` and `Skip` do not; a skipped clang oracle fails it unless
  `--no-clang`. `Error` is a test that could not be judged (a malformed
  `test.txt`, the pre-image not accepted by clang, a `post/` file equal
  to its `pre/` file); it is never blessed away.
- **Reading the run.** The ids come from the output lines of
  `spec/edits.md` §10.5 (`transform`, `edits`, `declared`, `overlay`,
  `result`, and `round`); the state from the last `state` line. A run
  that prints no `result` line where the expected state needs one is a
  `Fail` that shows the standard error.
- **The work directory** of a test is
  `<target>/transform/<area>/<name>/`, removed and made again for each
  run (by explicit path), with `tree/`, `store/`, and one directory per
  oracle that needs its own (`determinism/`, `back/`). Nothing is
  written elsewhere. A failing test's directory is kept and its path
  printed.
- **Mutation** needs the store's layout (`spec/edits.md` §10.4) to read
  the `EDTS` and to publish the mutated ones; it writes them with the
  store's publishing rule (a temporary name, then rename) and gives
  them to `slip check --edits <file>`.
- **The gate's step**: `cargo xtask ci` runs `cargo xtask transform`
  when `tests/transform/` holds at least one test, and prints today's
  line (`transform: no transform tests yet (spec/harness.md §6)`) when
  it holds none. `--quick` skips the step as it does today.
- Parallelism: tests run at once up to `-j`, each holding one job token
  for itself (its `slip` takes its own, `spec/harness.md` §5).

## Tests

`xtask/tests/transform.rs`, with fixtures under `xtask/tests/transform/`
and the stand-in `fake-slip`, which reads a script from the test's tree
(`fake.txt`: what to print, what to write, what to exit with, per
invocation) so that each rule of the runner is shown without Slip:

- `parse_test`: every directive, the defaults, each malformed form;
- a passing test; each single difference (status, state, a line of the
  output, a file different, a file added, a file missing) is a `Fail`
  whose message names it;
- normalisation of ids and of the tree's path;
- `--bless` rewrites `expect.txt` and `post/` and not `test.txt`; it
  refuses when state or status differ;
- each oracle passing, failing, and turned off by `oracle: no-<name>`;
  a run that writes although its state does not permit it;
- `mutations`: the count and the labels for 1, 8 and 20 edits, for 0,
  1 and 6 `kept` ranges and for 0, 1 and 6 spelled pieces; the added
  edit has the pieces of the first edit; a changed key is the bitwise
  complement and nothing else of the set differs; a mutated set
  validates as `EDTS`;
- a mutation that `fake-slip` reports `verified` fails the test with
  the label; `verified_with_residue` passes for a dropped edit only if
  the dropped range is among the residue lines, and fails for an added
  edit and for a changed key;
- `xfail`: `XFail` and `XPass`;
- the clang oracle with a stand-in compiler script: skipped and counted
  when there is none; `--no-clang`;
- `xtask/tests/ci.rs`: the step's line with no tests (unchanged) and
  with one.
