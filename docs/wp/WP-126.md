## Scope

Two notes of the last re-check of `docs/wp/WP-041.md`
(`spec/landed/digest/WP-041.md`, "After the re-check of round 5").

1. **The friend rule is wider than it needs to be.** A friend
   declaration in a templated stream that names a member is
   indeterminate (`spelling/friend-name`): Kiln resolves the friend and
   keeps neither the written qualifier nor its arguments, and
   `friend struct Bq<sizeof(sizeof(f(T())))>::Y;` hides an own spelling
   there. But `friend struct Inner;` and `friend struct __sentinel;`
   (the ranges views of both standard libraries) are hit too. The
   reviewer's narrower condition: a befriended member that is **not a
   specialisation** and whose semantic context is **the friend
   declaration's own class or a class enclosing it** is exempt. The
   argument: such a member is a member of the current instantiation; a
   qualifier that names the current instantiation is dependent, so it
   cannot hold an operand that is instantiation-dependent and not
   dependent, which is all rule 11 looks for. The test reads the
   target's context, not the written form (Kiln drops it).
   - Attack the argument before using it: a qualifier that reaches the
     same member through a base (`friend struct Base<..>::Y` where `Y`
     is also the enclosing class's member by inheritance: is the
     target's context then the base, so it stays lost?); through a
     member alias of the enclosing class; a member of an enclosing
     class named with explicit arguments that are not the template's
     own (`friend struct Outer<sizeof(..)>::Inner` inside
     `Outer<T>::Mid`: another specialisation, so not the current
     instantiation: what does Kiln give as the target's context?); a
     friend function and a friend class each way. Every form in which
     clang 19 accepts side A and rejects side B (the reviewer's method)
     must stay indeterminate or `differ`.
   - Numbers: units indeterminate with the cause over the
     standard-library translation units the harness parses, before and
     after.
   When Kiln records a friend's written qualifier and arguments (KB6
   section 9, the amendment of 2026-11-23), the rule becomes "read
   them": leave the note.
2. **Resolved and default-argument units** (`crates/slip_digest/src/demand.rs`)
   write no spelling list, in the first writing or the trace's. Either
   no fact can be pushed while one is written (say why, and assert it:
   a debug assertion or a test that walks every pair), or one can and
   it is dropped: then a pair that shows it, and the list written.
3. `a_list_changes_only_the_units_that_write_one`: if WP-041 left the
   relaxation skipping every `spelling/*` cause of a pending pair, skip
   only the cause the pair's own line names.
