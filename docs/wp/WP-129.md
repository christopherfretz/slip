## Scope

The first brief of `docs/wp/WP-091.md` wrote the queries' conformance
tests from the text of `spec/api.md` alone and listed where the text
and the host part, and where the text says nothing
(`spec/landed/api/WP-091-queries.md`: the subjects and the host's
answers are there). This package settles each. The rule for all of
them: the text is what a second implementation is written from, so
every answer ends as a sentence of `spec/api.md` and a test directory
under `crates/slip_script/tests/api/`; where the host is wrong the host
changes; where the choice is a design choice with a cost either way,
propose and stop for the supervisor (marked **ask**).

**The two disagreements** (both are `xfail` directories today):

1. §6.7 rule 8 names a counter `api.calls_without_reference`; §7.6
   rule 6 does not list it; the host has a method of the Kiln subject
   and no counter (`spec/landed/api/WP-086.md` decision 7). The rule's
   purpose is that a user can see that a call was not returned. Make
   the count visible in the run's output as the text says, and list it
   in §7.6, unless the landed decision's reason still holds: then
   **ask**.
2. §5.4 "A range inside one group of a conditional is a range"; the
   host gives a null extent to an argument when directive lines stand
   between its `,` and `)` (`WP-086.md` decision 9), also for
   `f(1,` / `#if 0` / `2` / `#endif` / `3);`. Decide what an argument's
   extent is when a directive line stands between the separators: the
   tokens of the argument alone (a range that holds no directive and is
   inside one group) is what the text promises. State what an edit
   that replaces or removes such an argument does to the directive
   lines beside it (nothing: they are outside the range), and what
   list-aware removal (the separator) must refuse. **Ask** if the
   answer changes what `remove` of an argument may do.

**The silences** (each: a sentence in the text, a directory):

3. §4 rule 2 and the second objection: a failed run's rendering holds
   the first line of a diagnostic no spec fixes. Give the test format
   an expectation that names the kind of failure only
   (`spec/harness.md` §6), and say in §4 what of a failure is
   specified (the error's code and the query) and what is not (the
   words).
4. §5.4 rule 3: a call in a macro argument used twice is two calls
   (the host agrees): say so.
5. §5.5: a member only an explicit specialisation declares cannot be
   named by `lookup`. Say what `lookup("S::k")` gives (nothing, with
   the reason), and whether another query reaches such a member; if
   none does, the sentence about its origin is unobservable in version
   0: mark it so.
6. §6.2 rule 3: `is_template` is true of an alias template, false of a
   concept (the host's answer); say whether an alias template is also
   `is_type`.
7. §6.3 rule 1: the identifier of `typedef struct { int m; } T;`.
8. §6.4 rule 3: `declarations_of` the global namespace; whether an
   explicit specialisation is a declaration of its template.
9. §6.5 rule 4: is the `n` of `template <n::C T>` a reference to `n`
   (it must be: a relocation of `n` rewrites it; check the host and the
   written-reference table, a For Kiln item if the entry is missing).
10. §6.5 rule 4: references imported from a precompiled header or a
    module: say that the script-test format cannot set one up, and
    where it is tested instead (name the test or write it).
11. §6.7 rule 5: a pack expansion as one written argument has nothing
    to apply to in version 0: mark it as a rule of a later version.
12. §6.7 rule 8: fixed by item 1.
13. §6.1: `lookup("S::S")` and the constructor (and `S::~S`, an
    operator, a conversion function: one table).

**The first objection**:

14. §6.6 rule 4 lets the host return null "when the host cannot
    establish the first or last token exactly": no test can require a
    range. Replace the clause by the list of shapes that may be null
    (as `spec/landed/api/WP-084.md` decision 3 does for macros), each
    with a directory, and a counter for a null extent outside the
    list so a host that falls back is seen.
