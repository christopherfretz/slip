# WP-086 — slip_script: the subject over Kiln: calls and expression extents

- Status: in-progress
- Milestone: M3
- Track: E
- Needs: WP-081, WP-083, WP-084
- Size: L
- Parallel with: WP-085, WP-087..089

## Scope

Launch after Slip's Kiln revision is on Kiln main (the callee's reference
is found in the written-reference table).

`spec/api.md` §6.7, §6.6 rules 3 and 4, §7.4 rule 3 for expressions. In
`KilnSubject`: `calls_to`, `callee`, `callee_reference`, `arguments`,
`extent` and `place` of an expression, and the declaration that holds an
expression (WP-095 turns it into a unit key).

What is decided:

1. **The index.** One walk of the bodies and initialisers of every
   written declaration (not of instantiations: §6.7 rule 2), on the first
   `calls_to` of the unit, recording for each call expression of rule 1:
   the callee's origin, the expression, the declaration that holds it.
   The walk is iterative or runs under `slip_digest::STACK_SIZE`.
2. **The callee's reference** is the table entry whose name range is the
   callee expression's name location. If none is found the expression is
   not a call (and a counter `api.calls_without_reference` says how
   many): `callee_reference_of` never returns null (§6.7 rule 4).
3. **Extents are exact or null** (§6.6 rule 4). `Ast::begin_loc` and
   `Ast::end_loc` are not exact for every kind. Until
   `docs/requests/KE1-expression-extents.md` lands, an extent is given
   only for the expression kinds in the table this package writes into
   `spec/landed/api/WP-086.md`, each with the reason its first and last
   token are known; every other kind gives null. Start from: a name, a
   literal, a parenthesised expression, a call, a member access, a
   subscript, a unary and a binary operator whose operands have extents.
   With KE1, the table is replaced by Kiln's answer.
4. An argument that is a default argument, or that an implicit
   conversion wraps, is reported as written: the wrapper is skipped, the
   default is absent (§6.7 rule 5).

## Tests

`crates/slip_script/tests/subject_calls.rs`:

1. §6.7 rule 1: each of the six forms is a call, with callee, reference
   and arguments.
2. Rule 2: each thing that is not a call.
3. Rule 5: default arguments; the object of a member call; a pack
   expansion; an argument that is a macro invocation (extent tier 0 over
   the whole invocation); an argument inside a macro argument (tier 1).
4. A call in a template pattern is returned once; none of its
   instantiations is.
5. A call in a lambda body, in a default member initialiser, in a
   default argument, in a `static_assert`, in a `requires` expression.
6. Extents: for every kind of rule 3, the exact bytes; for three kinds
   outside it, null.
7. **Differential**, when `clang++` 19 is on `PATH` (skip visibly
   otherwise): over the digest pair-test snippets, every call's extent
   and argument extents equal clang's `-ast-dump=json` ranges mapped to
   bytes; a null is allowed, a different range is not.

`calls_to`, `callee`, `callee_reference`, `arguments`, `extent`,

- The conformance differential (`SLIP_WP086_CONFORMANCE=1`, about three

For Kiln (in `spec/landed/api/WP-086.md`, with reproducers): a
qualified name's begin is its name in `Q::f(*this, 1)`
(`kiln_ast/src/ast.rs:289`); no node for the braces of `f({x})`

A release build was used once, for one measurement, because the debug

### Review fix round (F1 to F7)

- **F1** (wrong extent through a macro): the argument condition is
  decided in the token stream after expansion
  (`Tokens::expanded_kinds_around` in `slip_kiln`, which follows Kiln's
  macro entries as `file_loc_at_macro_start` does); an argument split
  over entries has no known neighbour, so null. `M(x)` with
  `#define M(a) f({a})` is null; `R(a)` and `R2(a)` (two macros) give
  «a» at tier 1. Test
  `s6_6_rule4_an_argument_through_a_macro_is_all_of_the_expanded_argument`.
- **F2** (silent miss): the postfix test reads the kind of the stored
  closing token (`Tokens::kind_of`), not the order of locations.
  `CALL1(f)`, `handle_##n()`, `CALL(o.mm, 3)` are calls (extent the
  invocation, or null). Invariant in §6.7 rule 8: every call expression
  the walk visits is returned, counted without a reference, or counted
  as not written (`extent_census().not_written`, `.visited`). Tests
  `s6_7_rule1_a_callee_from_a_macro_argument`,
  `s6_7_every_call_visited_is_returned_or_counted`.
- **F3** (wrong arguments): the implicit object of a function with an
  explicit object parameter is stripped (`f(2)` in a member gives
  `[«2»]`). `S::f(obj, …)` naming such a function is ill-formed (clang:
  "call to non-static member function without an object argument"), so
