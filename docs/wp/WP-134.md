## Scope

The independent review of `docs/wp/WP-131.md` found no defect and four
gaps in what the tests hold. This package closes the three that are
tests. No source of `crates/slip_digest/src/` changes; a test that shows
a defect is reported, not fixed here.

1. **Names that follow their pattern are pinned.** In
   `follows_pattern` (`crates/slip_digest/src/keys.rs`), answering
   `false` for `Operator`, for `Constructor`, or for every `UnnamedBy`
   survives every test: following differs from not following only
   through the checks of `docs/wp/WP-119.md`. Add cases under
   `crates/slip_digest/tests/rules/` where a rule on the plain key of an
   instantiation's operator, of its constructor, and of an unnamed class
   named by an identifier member is indeterminate
   `key/rule-on-instantiated-member`, and a case where a rule on the
   pattern's operator and constructor reaches the instantiation's
   (equal). Each of the three mutations must then fail a named case.
2. **The invariant's tables** (`crates/slip_digest/tests/inert.rs`):
   add a table whose rule has a parent the source declares and a name
   it does not; run the namespace table with the read-only files of the
   directories that have them; run the every-kind table with every file
   owned. Say in the file's header which tables run under which
   ownership.
3. **Six cases from the review** become directories of
   `crates/slip_digest/tests/rules/inert/` (their sources are the
   reviewer's probes; the supervisor hands them over as text in the
   brief): a partial specialisation's instantiation, an inherited
   constructor with a using-shadow of a conversion, explicit
   specialisations of members of an instantiation, conversions to
   pointer-to-member and function-pointer types that mention a relocated
   entity, a rename of a member class that is a conversion's target, a
   rename of a member function holding a local class. Each fails under
   "the predicate always true".
