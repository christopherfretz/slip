## Scope

`crates/slip_model/src/wire.rs`, `hash.rs`, `container.rs`, implementing
`spec/model.md` §2 (with §2.1), §3 and §5 (with §5.2). The three module files
exist as stubs; `lib.rs` already declares them.

## Interface

Names are fixed; details not stated here are yours to choose and document.

```rust
// wire.rs
pub enum ErrorKind { Truncated, Malformed, TooLarge, BadMagic, UnsupportedVersion, UnknownSection, Corrupt }
pub struct Error { pub kind: ErrorKind, pub offset: usize, pub what: &'static str }   // Display + std::error::Error
pub struct Encoder { /* over Vec<u8> */ }
//   new, u8, bool, uv(u64), sv(i64), bytes(&[u8]), str(&str), digest(&Digest), count(usize), into_bytes
pub struct Decoder<'a> { /* over &'a [u8] */ }
//   new, u8, bool, uv, sv, bytes -> &'a [u8], str -> &'a str, digest, offset, remaining,
//   count() -> usize  (a list count, rejected with TooLarge when it exceeds the bytes remaining),
//   finish() -> Result<(), Error>  (Malformed if bytes remain)

// hash.rs
pub struct Hasher;                 // new, update(&[u8]), finalize(&self) -> Digest
pub fn content_digest(bytes: &[u8]) -> Digest;
pub fn tagged_digest(tag: &str, encoded: &[u8]) -> Digest;    // BLAKE3(tag ‖ 0x00 ‖ encoded)

// container.rs
pub struct Writer;                 // new(kind: [u8; 4], version: u32), section(id: u64, payload: &[u8]), finish() -> Vec<u8>
pub struct Reader<'a>;             // open(bytes, kind, max_version) -> Result<Reader<'a>, Error>  (§5 rule 5, in that order)
//   version(), content_id() -> Digest, section(id) -> Option<&'a [u8]>, ids() of all sections present,
//   finish() -> Result<(), Error>  (UnknownSection if a critical section present was never requested)
```

`Writer::section` called with a non-ascending or zero id is a programming
error (panic with a message). Every reader-side rule of §5 is an `Error`.

## Tests

- `crates/slip_model/tests/wire.rs`: every primitive round-trips; boundary
  values of `uv` (0, 127, 128, 2^63, 2^64−1) and `sv`; every rejection of
  §2.1 that applies, each with the expected kind and offset (non-minimal
  `uv`, an 11-byte `uv`, a tenth byte above 1, bad `bool`, invalid UTF-8,
  truncated values, a count larger than the remaining bytes, leftover bytes
  at `finish`).
- `crates/slip_model/tests/blake3.rs`: the official BLAKE3 test vectors for
  the hash mode, every input length in the published set, as a committed
  fixture (the vectors are in the BLAKE3 repository,
  `test_vectors/test_vectors.json`: the input is bytes `i % 251`; keep the
  input lengths and the first 32 bytes of each `hash`). Also: incremental
  updates in pieces of 1, 63, 64, 65, 1023, 1024 and 1025 bytes equal the
  one-shot digest; `tagged_digest`.
- `crates/slip_model/tests/container.rs`: one test per rule of §5 (order,
  duplicate id, critical unknown, ignorable unknown skipped, bytes after the
  trailer, each open check and their order, truncated at every length of a
  small valid file, a flipped bit anywhere gives `Corrupt` or an earlier
  error but never success).
