# WP-003 — slip_cdb: splitting, response files, normalisation, ByExtension

- Status: done
- Milestone: M0
- Track: D
- Needs: none
- Size: M
- Parallel with: WP-001, WP-002, WP-004, WP-005

## Scope

`crates/slip_cdb/src/split.rs`, `rsp.rs`, `normalise.rs`, `check.rs`,
implementing `spec/cdb.md` §3, §4, §5 and §6. The module files exist as
stubs; `lib.rs` already declares them. The model types you need
(`Command`, `Language`, `Reason`) are in `slip_model`.

## Interface

```rust
// split.rs
pub struct SplitError { pub offset: usize, pub message: &'static str }
pub fn split_command(s: &str) -> Result<Vec<String>, SplitError>;       // §3
pub fn split_response(s: &str) -> Result<Vec<String>, SplitError>;      // §4 (GNU rules)

// normalise.rs
pub struct Exclusion { pub reason: slip_model::Reason, pub detail: String }
pub struct Normalised { pub command: slip_model::Command, pub main: std::path::PathBuf /* real path */ }
pub fn normalise(directory: &str, arguments: &[String], file: &str) -> Result<Normalised, Exclusion>;   // §4 then §5

// rsp.rs
pub fn expand(directory: &std::path::Path, arguments: &[String]) -> Result<Vec<String>, Exclusion>;    // §4

// check.rs
pub trait FrontEndCheck { fn check(&self, command: &slip_model::Command, main: &[u8]) -> Result<slip_model::Language, Rejection>; }
pub enum Rejection { UnsupportedLanguage(String), UnsupportedFlag(String) }
pub struct ByExtension;      // §6
```

The option tables of §5 are data in one place, each row citing the spec.

## Tests

`crates/slip_cdb/tests/split.rs` and `tests/normalise.rs` as listed in
`spec/cdb.md` "Tests": one case per rule, per table row and per exclusion;
idempotence of normalisation; and at least five commands in the shape CMake
writes for LLVM (long lists of `-D`, `-I`, `-isystem`, `-std=c++17`, `-o`,
`-c`, `-MD -MT -MF`), with the exact expected `argv`. Tests that need files
create them in a temporary directory they remove.

## Done when

The tests pass; clippy with `-D warnings` and `cargo fmt --all --check` are
clean; no dependency was added.
