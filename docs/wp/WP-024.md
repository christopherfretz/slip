# WP-024 — slip_digest: the framework of the walk, keys, units and types

- Status: in-progress
- Milestone: M1
- Track: C
- Needs: WP-021, WP-022, WP-023
- Size: L

## Scope

The first code of the walk: everything `spec/digest.md` defines that is
not a table of one area, plus the two areas every other one needs (keys
and types). After this package the remaining areas (declaration
payloads, statements, expressions, constants, templates, attributes and
the other tables, demand-driven fields) are filled in by packages that
run **in parallel, each in files of its own**, so the shape this package
gives the crate is its most important result.

In scope, by spec section:

- digest §2 (units: which entities, declared and derived, the
  worklist that makes an implicit entity a unit when a stream refers to
  it), §3 (keys, discriminators, entities without a name, mapped keys
  with `slip_model::keys::RuleTable`, collisions, merged namespaces),
  §4 (streams, `Ref`, local ordinals and local types, the memo of type
  digests), §10 (indeterminate units), §11 (groups, subject paths,
  detail), §12 (counters);
- digest-kinds §2 (reading a table as a stream: order, flag words,
  empty forms, redeclarations, declarations in place), §3 (keys), §4.1
  to §4.3 and §4.5 (the type digest: `Quals`, `TypeView`, `BuiltinType`
  and the small enumerations of §4.3, function types), §4.6 (`Nns`,
  `TemplateName`, `ArgView`: needed by types and by the keys of
  specialisations), §5.1 to §5.3 (a declaration's stream; which
  declarations are units; the rows of `DeclKind`, `DeclNode`,
  `DeclFlags`, `DeclMisc`, `Access`, `ModuleOwnership`, `Redecl`);
- the runner of the pair tests (digest §14, digest-kinds §1.5) and the
  determinism test.

Not in scope, and left as **pending** (below): every `record T`, `enum
T`, `child`, `value`, `attrs`, `profile` and `decl` whose table is in
digest-kinds §4.4, §5.4 to §5.8, §6, §7, §8, §9, §10, §11; the order
unit; resolved units; traces (localisation).

All tags and decisions come from the generated `crate::tables`
(WP-023); a number written by hand in the walk is a defect.

## Interface

**Public** (`slip_digest`), fixed here; the worker, the verify job and
every test use it:

```rust
pub struct Input<'a> {
    pub ast: &'a kiln::ast::Ast,
    pub sm: &'a kiln::source::SourceManager,
    /// The subject path of a buffer (digest §11): the caller knows the
    /// roots. Empty for a buffer that is no file.
    pub subject_path: &'a dyn Fn(kiln::source::FileId) -> Vec<u8>,
}

pub enum Detail<'a> {
    None, All,
    Groups(&'a [(GroupClass, Vec<u8>)]),
    /// digest §11: every group whose sum is not in the list, and every
    /// group with an indeterminate unit.
    Differing(&'a [GroupSum]),
}

pub struct Options<'a> {
    pub rules: &'a slip_model::keys::RuleTable,
    pub detail: Detail<'a>,
    /// Fill `Output::names`.
    pub names: bool,
}

pub struct Output {
    pub digests: slip_model::digests::Digests,
    /// digest §12, sorted by name; plus `digest.indeterminate.<cause>`.
    pub counters: Vec<slip_model::Counter>,
    /// Why each indeterminate unit is one (the first cause met), sorted
    /// by key.
    pub causes: Vec<(Digest, Cause)>,
    /// For every unit, the entity as a person would write it
    /// (`verify.md` §6 `name`); sorted by key; empty unless asked.
    pub names: Vec<(Digest, String)>,
}

#[non_exhaustive]
pub enum Cause {
    /// An invalid declaration, an error-recovery node, an error type.
    Error,
    /// A row decided `unsupported`: `<short name>/<row>`.
    Unsupported(&'static str),
    /// A set bit or a value no row accounts for (digest-kinds §2.1).
    Unaccounted(&'static str),
    /// digest §3.4.
    Collision,
    /// A local type no unit's walk declares (digest §4.3).
    UndeclaredLocal,
    /// An area of the walk that is not written yet. Removed from this
    /// enumeration, with `Area`, when the last area lands.
    Pending(Area),
}

/// Never fails: what cannot be digested is an indeterminate unit.
pub fn digest(input: &Input<'_>, options: &Options<'_>) -> Output;
```

`slip_model::digests::GroupSum` is added by this package if `main` has
no such type (the sum of a group, with `Group::sum()`).

**Internal**: one context type (`Walk`) owning the memo, the key table,
the worklist and the unit being written; one `Stream` type that is the
only way bytes reach a hash (the primitives of `spec/model.md` §2, flag
words gathered as digest-kinds §2.1 says, optional and list forms, and
`indeterminate(cause)`); and for each area a module with the functions
the rest of the walk calls, in the encodings' terms:

| Encoding (§1.3) | Function of | Module, owner |
|---|---|---|
| `ref`, `key`, `keyed`, `name`, `sym` | `Walk` | `keys.rs`, `refs.rs`: this package |
| `type` | `Walk` | `types.rs`: this package |
| `record T` / `enum T` of §5.4–§5.8 | one function per table | `decl_data.rs`: pending |
| `decl` (§2.4) | | `local.rs`: ordinals and local types here; the rows pending with §5 |
| `child` (statement) | | `stmt.rs`: pending |
| `child` (expression), `profile` | | `expr.rs`: pending |
| `value`, `string` | | `value.rs`: pending |
| `record`/`enum` of §9, template heads, `TemplLink` | | `templ.rs`: pending, except what keys need (below) |
| `attrs`, §10 tables | | `attrs.rs`, `other.rs`: pending |
| resolved units, §11 | | `demand.rs`: pending |

A pending function has its final signature and the body
`w.pending(Area::X)` (the unit becomes indeterminate with
`Cause::Pending`, and a fixed placeholder is written so that the stream
stays well formed). The package that fills an area replaces bodies in
its module and removes nothing else. **What keys need is not pending**:
a function's discriminator, a template head, the canonical arguments of
a specialisation and the `TemplLink` kind that says whether a
declaration is a pattern, a specialisation or a member of one are
written here as far as §4.6 and types reach; where one of them holds an
expression or a constant (a non-type argument, a requires-clause), the
pending function is called, the key is still computed, and the unit is
indeterminate until the area lands. Say in the handback which keys that
leaves colliding.

The dispatch over a Kiln enumeration lists every variant (digest §13
obligation 2): no `_` arm, no `..` over variants; a view is
destructured without a rest pattern (digest-kinds §4.1).

Record the internal interface as it ends up (every function another
area calls, with one line each, and "how to fill an area") in the
crate's `lib.rs` documentation, and whatever the spec left open in
`spec/landed/digest/WP-024.md`.

**Properties that are not negotiable**

- Determinism (digest §1 rule 3): nothing iterates a hash map into a
  stream or into the output; no arena index, address or interning order
  is written. The same input gives the same `Output`, bytes for bytes,
  in the same process and in another.
- Linear work: each type digested once per parse, each unit written
  once; the worklist of derived units ends because a unit is added at
  most once. A translation unit of LLVM has several hundred thousand
  declarations: no quadratic step over the declarations of a scope or
  the redeclarations of an entity.
- Recursion follows the AST's depth (types, nested classes). Say in the
  handback what bounds the stack (Kiln's stack guard through
  `slip_kiln`, or an explicit stack) and add the test.
- No panic on any AST Kiln can build: an unexpected shape is
  `Cause::Unaccounted`, not an `unwrap`.

**The pair tests.** One directory per test, under
`crates/slip_digest/tests/{differ,equal,demand,indeterminate}/<short
name>/<row>/` for a row's test and under `…/_/<slug>/` for a test no row
names (the tables test ignores `_`). A directory holds:

- `t.cpp`, which begins `#include "side.h"`; the runner supplies
  `side.h`, empty for side A and `#define B 1` for side B, so that both
  sides have the same lines. Or `a.cpp` and `b.cpp`. Other files are
  headers both sides see. A first line `// std: c++17` chooses the
  language (default `c++20`). Parsed with `slip_kiln::snippet`; a side
  with an error diagnostic fails the test (except in `indeterminate`,
  where `// errors: yes` allows them).
- `expect.txt`, lines of `changed <name>`, `added <name>`, `removed
  <name>`, `indeterminate <name>`, `derived-changed <name>`; `#`
  comments. Names are those of `Output::names`.

What each runner asserts (`tests/differ.rs`, `equal.rs`, `demand.rs`,
`indeterminate.rs`; one `#[test]` each that walks its directory, runs
every test, and reports every failure with its directory, not the
first):

- `differ`: over declared and `tu` units, the keys whose units differ
  between the sides are exactly the `changed`, `added` and `removed`
  lines (at least one line); derived units are free unless a
  `derived-changed` line names one, which must then differ;
- `equal`: the two `Digests` are equal with `Detail::All`; no
  `expect.txt`;
- `demand`: every key in both sides has the same digest and flags;
  `added` lines, if any, are exactly the declared keys only B has;
- `indeterminate`: side A only; the units flagged are exactly the
  `indeterminate` lines, and none has the cause `Pending`;
- in `differ`, `equal` and `demand`, a unit that is indeterminate for a
  cause other than `Pending` fails the test; `Pending` is tolerated
  while `Area` exists.

`tests/determinism.rs`: every source of every directory above, digested
twice in the process and (through a child process running the test
binary on one source: say how) once in another, equal each time.

## Tests

Pair tests under `_/` and under the rows this package implements. At
least: every key kind and every name form that needs no pending area
(digest-kinds §3, §5.2), each with a `differ` test that renames, moves
to another namespace, or changes the discriminator, and an `equal` test
of what must not matter (declaration order within a namespace, a
redeclaration added, `struct` against `class`, a qualified against an
unqualified spelling of a type, a typedef or alias in a signature); an
entity declared in a header and defined in the main file (one unit, in
the header's group); the unnamed-entity rules of digest §3.3, one test
each; two identical `static_assert`s being one unit is pending with
its payload: leave a `_` test marked `# pending` that the runner skips
and lists. Every `TypeView` variant that C++ can spell without a
template or an expression operand, and every `BuiltinType` that is a
C++ type, as `differ` tests under their rows; `Quals`; the rows of
`FuncProto` and `FuncInfo` (variadic, ref-qualifier, cv, `noexcept` as
far as §4.2 rules 3 and 4 allow without `ExcSpec`'s pending parts);
sugar that must be equal (§4.2 rules 2, 6; a typedef chain;
`decltype(x)` for a non-dependent `x`).

Unit tests in the crate: `Stream` (each primitive against
`slip_model::wire`; flag words; a list and an optional; two different
trees giving different bytes); groups (two files; a derived unit's
group; the `tu` group holding every namespace; `Detail` in its four
forms giving the same sums); rules (a namespace relocated: every key
under it as before, compared with the same source written the old way;
a namespace merged onto an existing one: two units of one key if they
differ, one if not; a class renamed; a collision: both indeterminate
with `Cause::Collision`); counters; names (qualified names; functions
with parameter types; the content-keyed and resolved forms).

Each name removed from `tests/tables/untested.txt` has its directory
(`SLIP_BLESS=1` does it).

## Done when

`cargo xtask ci` (the full gate) passes; `cargo test -p slip_digest`
takes under a minute once built; the handback gives, for the directory
`llvm/lib/Support` of the corpus if it can be run (it cannot before the
package after WP-020: then for the largest snippet the tests have), the
counters and the split of `digest.indeterminate` by cause; the rows
implemented and the rows left, by table; the keys that can collide
until their area lands.

## Out of scope

Everything pending. `scheme` stays 1 until the walk is complete: no
shard carries a digest before then. The worker and `slip verify`.
