# WP-170 — `slip_exec`'s tests make their scratch directories in the system temp

- Status: done
- Milestone: M1
- Track: H
- Needs: none
- Size: S
- Parallel with: every package that does not edit `crates/slip_exec/tests/`

## Scope

The integration tests of `slip_exec` make their scratch directories under
`std::env::temp_dir()` (the system temp, `/tmp` in the container). Every
other crate whose tests write files makes them under the shared work root
of `spec/harness.md` §11.5: `$SLIP_TEST_ROOT` when it is set and not
empty, else Cargo's `CARGO_TARGET_TMPDIR`. The rule is one file,
`crates/slip_kiln/tests/common/work_root.rs`, included by `#[path]` from
the `tests/common/mod.rs` of `slip_cli`, `slip_digest` and `slip_script`
(look at one of them: `crates/slip_cli/tests/common/mod.rs`). This is
"small packages owed" item 7's last part on the supervisor's side.

1. Add `crates/slip_exec/tests/common/mod.rs` that includes the same
   file (`#[path = "../../../slip_kiln/tests/common/work_root.rs"] pub
   mod work_root;`) and gives `pub fn work_root() -> PathBuf` returning
   `work_root::work_root_or(env!("CARGO_TARGET_TMPDIR"))`, as
   `crates/slip_kiln/tests/common/mod.rs` does. No new dependency: the
   file is included, not linked.
2. In each of `crates/slip_exec/tests/{store,process,worker,objects,jobserver,pool,signals}.rs`,
   every scratch directory made today under `std::env::temp_dir()` is
   made under `common::work_root()` instead, with the same name (tag,
   process id, counter). Keep each `Drop` that removes it (`Scratch`,
   `TestFifo`, `Guard`) as it is.
3. One `#[test]` in one of those files (or a small new file
   `tests/work_root.rs`) calls `common::work_root::self_test(env!("CARGO_TARGET_TMPDIR"))`,
   as the other crates do, so the rule is checked in this crate too.

Directories that hold a FIFO (`jobserver.rs`, `signals.rs`, `pool.rs`
line about 315) need a file system that makes FIFOs: the work root is on
the container's own disk, which does. If any test cannot run there, stop
and say which and why; do not fall back to the system temp.
