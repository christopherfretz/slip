# WP-136 — a specialisation whose substitution failed is no entity

What `crates/slip_digest` and `crates/slip_verify` do for Kiln's
`DeclArena::subst_failed` marks (Kiln WP-3281, pinned at `60fb5ab9d`,
`kiln/spec/ast.md` §4.1 "Silent failures", `kiln/spec/sema-templates.md`
§5.7.3).

Demo 1's run of record had 13,405 indeterminate units of node
`specialisation` with cause `error` — none of them errors, each a
SFINAE candidate whose substitution failed and which Kiln kept as an
`INVALID` declaration.

## What was built

- `crates/slip_digest/src/units.rs`:
  - `is_no_entity_failed_substitution`, `failed_substitution`, and
    `in_failed_substitution`: exhaustive match over `SubstFailedKind` (no
    wildcard, `spec/digest.md` §13 obligation 2), with an O(1) empty
    fast-path (`ast.decls.cold.subst_failed.is_empty()`), walking
    `closure_owner` / `ctx` (bounded at `SUBST_FAILED_LIMIT = 256` steps,
    matching Kiln's `Sema::decl_owner`) so valid closures, parameters and
    locals owned by a failed signature (kinds 1, 2) are also excluded. Past
    the 256-step bound, `failed_substitution` returns
    `FailedSubst::DepthLimit`, failing closed with
    `Unaccounted("decl/subst-failed-depth")` in `collect`, `decl_node`, and
    `write_ref` instead of silently dropping or accepting the declaration.
  - `invalid_cause`: classifies `DeclFlags::INVALID` using
    `DeclArena::subst_failed` — `None` -> `Cause::Error`;
    `ClassPartialAmbiguity` -> `None` when no definition, members or bases
    are present, else `Unaccounted("decl/class-partial-ambiguity")` (a real
    fail-closed path reached when a SFINAE partial-specialisation ambiguity
    on `X<int, int>` is followed by an explicit specialisation
    `template<> struct X<int, int> { ... };`); `OtherTrapped` ->
    `Unaccounted("decl/trapped")`; kinds 1, 2, 3, 5 ->
    `Unaccounted("ref/failed-substitution")` (renaming this cause for
    declaration-position kinds 1/2/3/5 is out of scope).
  - `unmarked_invalid`: counts declarations in `ast.decls.ids()` carrying
    `DeclFlags::INVALID` with `subst_failed == None`.
  - `collect` and `class_of`: skip declarations with
    `in_failed_substitution` so failed specialisations are never units (and
    `query::Keys::unit_of` agrees).
- `crates/slip_digest/src/decl.rs` (`decl_node`) and
  `crates/slip_digest/src/decl_class.rs` (`members`, `local_member`):
  use `units::invalid_cause` instead of blanket `Cause::Error`, flag
  `FailedSubst::DepthLimit` indeterminate, and defensively skip failed
  substitutions in local-class member lists.
- `crates/slip_digest/src/refs.rs` (`write_ref`): any `Ref` reaching a
  declaration with `FailedSubst::Yes` writes `REF_NONE` with
  `Cause::Unaccounted("ref/failed-substitution")` without queueing the
  target; `FailedSubst::DepthLimit` writes `REF_NONE` with
  `Cause::Unaccounted("decl/subst-failed-depth")`.
- `crates/slip_digest/src/{local.rs,demand.rs,emitted.rs,ns_refs.rs}`:
  skip `in_failed_substitution` declarations in full-arena scans
  (`number_all`, `unheld`, `is_local_default_holder`, `unplaced` — each
  individually exercised and killed in the mutation table below; plus
  defensive skips in `param_templates` and `ns_table` documented below).
- `crates/slip_digest/src/walk.rs`: emits `digest.invalid.unmarked`
  alongside `digest.emitted.unplaced` and `digest.instantiated.unheld`.
- `crates/slip_digest/tests/common/mod.rs`: asserts
  `digest.invalid.unmarked == 0` on every side with `errors == 0`.
- `crates/slip_cli/src/verify_job.rs` and `crates/slip_verify/src/run.rs`:
  `verify_job` carries a non-zero pre-image map shard
  `digest.invalid.unmarked` count into the verify shard as
  `verify.invalid.unmarked.pre`; `Report` folds both post-image
  (`digest.invalid.unmarked`) and pre-image (`verify.invalid.unmarked.pre`
  for `Verified`/`Mismatch`, and the `ok` map shard's
  `digest.invalid.unmarked` directly in `add_unchanged_at` for `Unchanged`)
  into `unmarked_invalid` (JSON) and
  `defect: unmarked invalid declarations: …` (text), without panicking and
  without changing reports where the count is 0.
- `spec/digest.md` (§2.1, §8, §10, §12), `spec/digest-kinds.md`
  (`DeclFlags` `0-invalid`, `ColdDeclData` `subst_failed` -> `out`,
  `SubstFailedKind`), `spec/verify.md` (§7.1, §7.2), `spec/pitfalls.md` (N47).
- Tests: unit tests in `crates/slip_digest/src/{units.rs,local.rs}`,
  `crates/slip_verify/tests/run.rs`, and `crates/slip_cli/tests/verify_job.rs`;
  20 pair tests across `differ/_/`, `equal/_/`, `demand/_/` and
  `indeterminate/_/`; pitfalls row
  `crates/slip_verify/tests/pitfalls/n47-candidate-removed-by-substitution/`.

## Decisions

1. **Answers from Kiln at pin `60fb5ab9d` (WP-3281)** to the two open
   questions in `docs/wp/WP-136.md`:
   - *"No pattern" for a variable*: not split from kind 3. A variable
     template specialisation whose template or matching partial
     specialisation is only declared takes the declaration as its pattern
     and is valid ([temp.inst]/7, `kiln/spec/ast.md` §4.1,
     `kiln/spec/sema-templates.md` §5.7.3).
   - *Closures of a failed signature*: a closure created while a failed
     signature was formed keeps the failed specialisation as its
     `closure_owner` (`kiln/crates/kiln_sema/src/templ/funcs.rs:158-171`).
     If the closure itself is invalid, Kiln marks it kind 5
     (`LocalOfFailedSignature`, `subst_failed.rs:484-503`); if valid, it
     is unmarked and owned by the kind 1/2 specialisation. Walking
     `closure_owner` / `ctx` in `in_failed_substitution` excludes both
     and treats any `Ref` to either as
     `Unaccounted("ref/failed-substitution")`.
2. **Kind 4 (`ClassPartialAmbiguity`)**: Kiln leaves an ambiguous class
   template specialisation under a trap as `SpecKind::Undeclared` with no
   definition, members or bases (`kiln/spec/ast.md` §4.1). In the digest
   it is not a unit (matching any never-instantiated class
   specialisation), `write_ref` writes its key determinately, and
   `invalid_cause` returns `None` provided definition, members and bases
   are all absent. Thus a failed attempt and no attempt produce identical
   digests (`equal/_/subst-failed-class-partial-ambiguity`). However, the
   fail-closed branch (`Unaccounted("decl/class-partial-ambiguity")`) is
   **real, not hypothetical**: a valid C++ program with a SFINAE ambiguity
   on `X<int, int>` followed by an explicit specialisation
   `template<> struct X<int, int> { using t = int; };` reaches it
   (`indeterminate/_/subst-failed-class-partial-ambiguity-then-explicit-spec`),
   because Kiln attaches the explicit specialisation's definition/members
   while `INVALID` + `ClassPartialAmbiguity` remains on the specialisation.
3. **Invariant counter on both pre-image and post-image without changing
   public interfaces**: `slip_digest::Input` does not carry diagnostic
   counts, and WP-136 adds no public item. `slip_digest` therefore always
   emits `digest.invalid.unmarked` (the count of `DeclFlags::INVALID`
   declarations without a `subst_failed` mark, matching Kiln's arena-wide
   invariant check). Wherever diagnostics are known (`errors == 0` in
   `tests/common/mod.rs`; accepted `ok` verify shards in
   `slip_verify::run::Report`, with `verify_job.rs` forwarding any non-zero
   pre-image map shard count as `verify.invalid.unmarked.pre`; and `ok` map
   shards of `Unchanged` observers in `Report::add_unchanged_at`), non-zero
   counts on either side are flagged — as a test failure in
   `tests/common/mod.rs`, and as an optional defect line and JSON member in
   `Report` (never a panic, and absent when 0 so M1 reports stay
   byte-for-byte identical).
4. **Digest `scheme` stays 3**: WP-136 changes no existing determinate
   unit's stream, key or table tag, and closes no wrong equal; it removes
   failed substitution specialisations that were previously indeterminate
   `error` units.
5. **`ColdDeclData` `subst_failed` is `out` in `spec/digest-kinds.md`**:
   the walk reads it to classify `DeclFlags` `0-invalid` and never writes
   it into a stream. `ColdDeclData/subst_failed` therefore leaves
   `tests/tables/untested.txt`.
6. **Scope item 5 ("succeeds and loses") and `subst-failed-tried-or-not`**:
   making a failing candidate succeed and lose to a more-specialised
   overload (`differ/_/subst-failed-succeeds-and-loses`) requires changing
   a trait (`Trait<int *>`, a declared unit) and produces the newly valid
   derived specialisation `g<int *>(int *)`, so the pair lives under
   `differ/_/` with `u(int *)` unchanged. `equal/_/subst-failed-tried-or-not`
   tests a separate claim: a failed candidate tried (via ADL) vs never
   tried (via qualified call) produces identical digests.
7. **256-step walk bound and O(1) empty fast-path**: `failed_substitution`
   returns `FailedSubst::No` immediately in O(1) when
   `ast.decls.cold.subst_failed.is_empty()`. Past `SUBST_FAILED_LIMIT = 256`
   steps it returns `FailedSubst::DepthLimit` rather than silently
   returning `false`; `collect`, `decl_node`, and `write_ref` flag it
   indeterminate with `Unaccounted("decl/subst-failed-depth")` without
   dropping the entity.
8. **Out of scope**: renaming `Unaccounted("ref/failed-substitution")` when
   `invalid_cause` sees a kind 1/2/3/5 declaration directly is out of scope.

## Per-kind summary

| Kind | `SubstFailedKind` | Kiln state at `60fb5ab9d` | Digest behaviour |
|---|---|---|---|
| 1 | `FunctionSignature` | `INVALID` function/method/ctor/conversion/guide spec (type `ERROR` or full signature on trapped error) | no unit, not listed, not read; `Ref` -> `Unaccounted("ref/failed-substitution")` |
| 2 | `ExplicitSpecifier` | `INVALID` ctor/conversion spec with full type, failed `explicit(expr)` | no unit, not listed, not read; `Ref` -> `Unaccounted("ref/failed-substitution")` |
| 3 | `VariablePartialAmbiguity` | `INVALID` variable spec (`Undeclared`, type `ERROR`) | no unit, not listed, not read; `Ref` -> `Unaccounted("ref/failed-substitution")` |
| 4 | `ClassPartialAmbiguity` | `INVALID` class spec (`Undeclared`, no definition/members/bases) | never-instantiated class spec (no unit when `Undeclared`, determinate `Ref` and decl) |
| 5 | `LocalOfFailedSignature` | `INVALID` local/param/closure owned by kind 1 or 2 | never reached; `Ref` -> `Unaccounted("ref/failed-substitution")` |
| 6 | `OtherTrapped` | any other trapped invalidation (pack probe, GMF merged duplicate, `local_tag_used_early`, reflection thunk) | indeterminate `Unaccounted("decl/trapped")` |
| — | `None` (unmarked `INVALID`) | real compilation error | indeterminate `Cause::Error`; counted in `digest.invalid.unmarked` |

## Item 4 ("Its kin")

| Kin shape | What Kiln keeps at `60fb5ab9d` | Digest result | Pair test |
|---|---|---|---|
| Member function template of an instantiation (`S<int>::m<int>`) | `CXXMethod` spec marked `INVALID` + `FunctionSignature` | no unit, 0 indeterminate; `u()` differs when it wins | `differ/_/subst-failed-member-fn-template` |
| Constructor template (parameter SFINAE, `function_ref` shape) | `CXXConstructor` spec marked `INVALID` + `FunctionSignature` (default template arg SFINAE fails during deduction with no spec kept; `explicit(expr)` is `ExplicitSpecifier`) | no unit, 0 indeterminate; `u()` / `s` differs when it wins | `differ/_/subst-failed-ctor-template`, `differ/_/subst-failed-explicit-specifier` |
| Conversion function template | `CXXConversion` spec marked `INVALID` + `ExplicitSpecifier` on `explicit(expr)` failure (default template arg SFINAE fails during deduction with no spec kept) | no unit, 0 indeterminate; `u(C)` differs when it wins | `differ/_/subst-failed-conversion-template` |
| Deduction guide | `CXXDeductionGuide` spec marked `INVALID` + `FunctionSignature` | no unit, 0 indeterminate; `a` differs when user guide wins | `differ/_/subst-failed-deduction-guide` |
| Class template partial specialisation that did not match | no failed declaration kept (`subst_failed_decls` empty) | 0 indeterminate; `u()` and `P<int, void>::<definition>` differ when it matches | `differ/_/subst-failed-class-partial-mismatch` |
| Variable template (ambiguous partial spec in SFINAE) | `Var` spec marked `INVALID` + `VariablePartialAmbiguity` (beside outer `FunctionSignature`) | no unit, 0 indeterminate; `x` differs when disambiguated | `differ/_/subst-failed-var-partial-ambiguity` |
| Alias template failing inside another's signature (`enable_if_t<false>`) | no declaration kept for the alias template itself; outer function spec is marked `FunctionSignature` when in return/parameter type (or none when in a default template argument) | no unit, 0 indeterminate; `u()` differs when condition flips | `differ/_/subst-failed-alias-enable-if` |

## Mutations

Each single-site mutation was applied in isolation and restored cleanly
afterwards. Four scan skips (`M7`, `M12`, `M16`, `M19`) are explicitly
**defensive** at Kiln `60fb5ab9d` (no valid C++ program can trigger an
observable difference without them); every other mutation is **killed**:

| Mutation | Site | Status & killing test / defensive reason |
|---|---|---|
| M1: failed specialisation is a unit again (`is_no_entity_failed_substitution` -> `false`) | `crates/slip_digest/src/units.rs` | **Killed** by `units::tests::wp136_kinds_1_to_3`, `wp136_lambda_and_kind5`, `wp136_its_kin_all_seven_cases`, `wp136_ref_to_failed_substitution_is_unaccounted` |
| M2: every invalid specialisation left out, error or not (`INVALID && spec_info.is_some()` -> `true`) | `crates/slip_digest/src/units.rs` | **Killed** by `tests/indeterminate/_/subst-failed-real-error` (`expected but not flagged: ["v<int>"]`) |

| M4: kind 4 (`ClassPartialAmbiguity`) treated as `Cause::Error` | `crates/slip_digest/src/units.rs` | **Killed** only through hand-set kind-4 mark in `units::tests::wp136_kind6_other_trapped_is_decl_trapped` (and `indeterminate/_/subst-failed-class-partial-ambiguity-then-explicit-spec` checks the non-empty fail-closed path) |
