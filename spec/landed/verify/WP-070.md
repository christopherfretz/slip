# WP-070 — agreement, spelled entities over the run, the overlay's guards, the state of a result

## 1. The reader of `RSLT`: what the file alone decides (`spec/edits.md` §8.5)

The rule of `spec/landed/edits/WP-061.md` ("whatever the file alone
decides, the reader checks"), applied to the three facts WP-061 left
out. Rows numbered after WP-061 §4's, in the order they are checked;
paths under `sections.result`.

| # | Rule | Offset / path | Message |
|---|---|---|---|
| 6a | for each failed spelling in turn: `observers` 0 iff `unseen`; then `first` absent iff `unseen`; then `found` absent for `unseen` | `spellings.failed[i].observers`, `….first`, `….found` | `observers is not 0 for unseen or is 0 for denotes_other`, `first is present for unseen or absent for denotes_other`, `found is present for unseen` |
| 8a | for each residue entry in turn: `lo < hi`; then `line` at least 1; then `column` at least 1 | `residue[i].lo`, `….line`, `….column` | `a residue's range is empty`, `a residue's line is 0: lines are 1-based`, `a residue's column is 0: columns are 1-based` |
| 13 | `unparsed` at most `selected` (every result, refused included) | `tally.unparsed` | `unparsed is more than selected` |
| 14 | with a `verdict`: the seven states add up, without overflow, to `selected − unparsed`; without one: each of the seven is 0, the first that is not | `tally.verified`; `tally.<field>` | `the states of the tally do not add up to selected less unparsed`; `a result without a verdict has a count of observers verified` |

- **6a.** `unseen` is "no observer could check it" (`spec/verify.md`
  §10.3): no observer counted, none named, nothing found.
  `denotes_other` failed in at least one observer, the first of which
  is named. A `denotes_other` may lack `found` (the origin had no key);
  `name` is for the report and is read for either kind. Beyond the
  follow-up's "`first` absent for `unseen`", `observers` and `found` are
  decided by the same fact and are checked with it.
- **8a.** A residue entry is an identifier token or a mention (§8.4):
  never empty. Whether `hi` is within the file needs the file and is not
  checked. `lo < hi` was not in the follow-up's list; it is decided by
  the file alone and is checked with line and column.
- **13, 14.** The seven states are those of the observers the verify
  phase selected (§8.2): the run's selected observers whose map shard is
  `ok`, which is `selected − unparsed`. A result without a verdict is
  one whose verify phase did not run or did not finish, and conclude
  then counts no state (§5 below); a refused result was row 12 already.
  Row 13 comes first so that row 14's target is defined.
