# WP-059 — Demo 1, the runner

`cargo xtask demo 1` (`xtask/src/demo.rs`) runs the cases of
`spec/harness.md` §10 (WP-043's, in `bench/demo1/`) through the `slip`
commands of WP-053 and writes the table and `demo1.json`. `xtask` does
not link `slip_cli`, and the demo does not use `slip_verify` (which xtask
already depends on for `transform`): reports are read with
`slip_model::json`, runs with `xtask::perf`.

Tests: `xtask/tests/demo.rs` (22), with a fake `slip` and the fixtures in
`xtask/tests/demo/`; goldens `partial.txt` and `partial.json` are
rewritten with `SLIP_BLESS=1`.

The corpus run (step C) is recorded below when it has been made.

## Decisions

Where §10 left a choice, the narrowest reading was taken.

1. A case's round is its 0-based position among all cases (as the `nn`
   of its name), also when `--case` selects a subset.
2. `edit.txt`: the old and new texts are byte strings, each line with its
   line feed; the occurrences of a `replace` may not overlap. Nothing is
   written if any entry fails. An edited file keeps its mode. A path
   through a symbolic link is refused. `create` makes missing parent
   directories.
3. Every path of `edit.txt` must lie under a root of `demo.toml`
   (`check_roots`), checked before anything is written.
4. `Entry` carries the line of `edit.txt` it came from, so that errors
   name it (an addition to the interface of §10.5).
5. A line of `expect.txt` with a place is matched against the group's
   `where` on the line's image. The empty site, or a group with no
   `where`, counts as no place. With several groups of the line's kind
   and name: any at the place gives found, else any without a place
   gives no-place, else WRONG.
6. A line of `expect.txt` with no place is found by kind and name.
7. A case whose verify selects 0 observers is ERROR.
8. The cause printed for a blocked line is the `what` of the
   indeterminate group of the same name on the line's image, else on the
   other image; with none, "no indeterminate group of that name in the
   report".
9. `slip units` is run with one `--match` per name not found.
10. A case with no `observers` file uses the demo's `--only` with
    `--limit 1`.
11. A failing `slip` command in a case makes that case ERROR and the
    demo goes on; a failing `slip plan` or `slip parse` is a command
    error (exit 1).
12. A pristine file changed after the run (an edit through a hard link)
    gives `FAILED (an edit went through a link: <files>)`.
13. `demo1.json` holds the table's data with paths relative to `src`;
    paths outside `src` (system headers) stay absolute.
14. A report that is not of the demo's plan and the case's round makes
    the case ERROR.
15. `declared.txt` counts as present only if it has a line that is
    neither blank nor a `#` comment.
16. `slip declare` gets `--owned <src>/<root>` for each root, after
    `--out` and before the image arguments `--root … --post …` (the
    coordinator's amendment to §10.3 step 3).
