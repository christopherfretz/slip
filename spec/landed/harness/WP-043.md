# WP-043 — the cases of Demo 1

The inputs of `spec/harness.md` §10.1 for the cases of §10.2, on the
`llvm` corpus at `llvmorg-19.1.7` (`bench/corpora.toml`), in
`bench/demo1/`: `demo.toml` (corpus `llvm`, root `llvm`, selection
`/llvm/lib/Support/`, 151 observers) and the eight cases. Each case's
`README.md` has the reasoning and the commands; this file has the
record.

## Amendments to §10.2

- `01-relocate`: `llvm/include/llvm/ADT/Hashing.h` has **three** blocks
  of `llvm::hashing::detail` (lines 134, 478, 602), not two; with
  `StableHashing.h` and `unittests/ADT/HashingTest.cpp` the namespace
  has five blocks in `llvm/`. Uses outside the root `llvm`
  (`bolt/lib/Profile/StaleProfileMatching.cpp:316, 329`) are left: an
  edit may not leave the roots, and no entry of the database compiles
  them.
- `03-overload`, `04-adl`, `05-shadow`: the sites chosen are below.
- `07-relocate-undeclared` has no `edit.txt` (its tree is its `base`'s,
  and an `edit.txt` with no entry is an error, §10.1): §10.1 says
  "absent for the control"; it is absent here too.

## The checks, common to every case

Each tree is `<corpus>/trees/wp043/<case>/llvm`: hard links of
`<src>/llvm` (or of the `base` case's tree), each edited file written as
a new file. The database's copy has `<src>/llvm/` replaced by the tree's
`llvm/` in `file` and `command`; the build tree, and `<src>` outside
`llvm/` (googletest), are the pristine ones.

1. **T2**: `clang++-19`, each command with `-fsyntax-only` in place of
   `-c` and `-o`, from the entry's directory. The pristine tree gives
   **no warning** in any of the units compiled, so every warning would
   be one an edit adds; **no case has one**.
2. **Kiln**: `slip parse --only /llvm/lib/Support/ -j 6` with the
   release `slip` at Slip's pin. On the pristine database: selected
   151, `ok` 151. No observer of the selection is excluded from any
   case's comparison.
3. **The pristine tree**: `git -C <src> status --short` empty before
   and after every case, run with `-c core.trustctime=false` (a hard
   link changes the ctime of the file it links, and git would re-read
   every linked file; content and mtime are still compared), and every
   file any `edit.txt` names hashes to its blob at `HEAD`.

## Names whose spelling is unconfirmed

No `slip units` was available; these follow `spec/verify.md` §6.1 and
clang's canonical spelling, and WP-059 corrects them if Kiln prints
otherwise: `unsigned long` for `size_t`, `unsigned int` for
`unsigned`, `const char *`, `const llvm::Twine &`, `llvm::StringRef &`,
`long long &`; the static function at global scope
`CommaSeparateAndAddOccurrence(…)` with no qualifier; the function
template `llvm::has_root_directory` without parameters, with
`[function_template]`; `llvm::hashing::detail` and
`llvm::hashing::impl` without a kind.
