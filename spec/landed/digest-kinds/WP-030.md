# WP-030 — attributes and annotations

What `crates/slip_digest/src/attrs.rs` reads into `spec/digest-kinds.md`
§10.1 and §10.5 where they are silent. Each choice is the conservative
one: where a fact could not be settled, the unit is indeterminate.

## The per-kind rows are data written by hand

`crate::tables` gives `AttrNode`'s per-kind rows as names and decisions
only (`attr_node::ROWS`), and `AttrKind` as constants with no mapping
from Kiln's numbers. So `attrs.rs` holds one table, `KINDS`: each
`AttrKind` row with its Kiln constant, its generated `Row`, and its
per-kind operand rows, each with its encoding. Unit tests keep it equal
to the generated table (every row once, in table order, same tags and
decisions, the per-kind rows of each kind in table order with their
decisions) and to the constants of Kiln's `kiln_ast/src/attr.rs`
(every constant has a row, with its number). A row added to either side
fails those tests until `KINDS` follows.

## The encoding `attrs`

- **Chain order** is first declaration to last (the reverse of
  `Ast::redecls_of`), and within a declaration the stored order. A node
  with flag bit 1 (`flags-inherited`) is left out of a declaration's
  list. Kiln has no constant for the bit; `attrs.rs` names it `INHERITED`
  with the Kiln site that sets it (`kiln_sema/src/decl.rs`, the inherited
  asm label). A statement's list is written whole: there the bit is
  accounted for and not read.
- **A list or id that names nothing** (a list index past the arena, an
  attribute or annotation id past its arena) is
  `Unaccounted("AttrArena/decl_attrs")` or
  `Unaccounted("AnnotArena/of_decl")`; the id is left out.

## `record AttrNode`

- **Order** is that of §2.1: `kind`, `syntax`, one flag word
  (`flags-implicit`, then the kind's `bit` rows in table order), then the
  kind's `in` operand rows in table order. `loc` and the `out` rows
  write nothing.
- **Every bit is accounted for.** The flag bits a node may have are
  bits 0, 1 and 3 (the rows without a kind) and the bits its kind's rows
  name; any other set bit is `Unaccounted("AttrNode/flags")`. The bits of
  `a` and of `b` a node may have are those its kind's rows read (a row on
  the whole word, or the masks of `NO_SANITIZE`'s `b` rows); a set bit
  outside them, which includes any non-zero word of a kind with no row
  for it, is `Unaccounted("AttrNode/a")` or `Unaccounted("AttrNode/b")`.
- **A kind with no row** (a number Kiln added) writes `uv 0` for its kind
  and is `Unaccounted("AttrNode/kind")`; its words are then unaccounted
  for unless 0.
- **An `unsupported` row** is `Unsupported("AttrKind/<row>")` for a kind
  (the `unbuilt` kinds, should one be met) and
  `Unsupported("AttrNode/CLEANUP.a")` for `CLEANUP.a`; nothing is written
  for the operand.
- **Values a note bounds.** Where a row's note lists the values
  (`VISIBILITY.a` 0 to 2, `TYPE_VISIBILITY.a` as it, `TLS_MODEL.a` 1 to
  4, `CODE_MODEL.a` 1 to 2, `ENUM_EXTENSIBILITY.a`, `XRAY_INSTRUMENT.a`,
  `FUNCTION_RETURN.a`, `LIFETIMEBOUND.a`, `PASS_OBJECT_SIZE.b`,
  `TARGET_CLONES.b` 0 to 1, `PASS_OBJECT_SIZE.a` 0 to 3, `ARM_NEW.a` its
  two bits, `ZERO_CALL_USED_REGS.a` and `PRAGMA_CLANG_SECTION.b` an index
  into Kiln's array, `NO_SANITIZE.b-spelling` an index into
  `NO_SANITIZE_SPELLINGS`), another value is written as found and is
  `Unaccounted("AttrNode/<row>")`.
- **Ids in operands.** An `ExprId`, `StringLitId`, `QualType`, `ListId`
  or `Symbol` index past its arena is `Unaccounted("AttrNode/<row>")`,
  with a fixed placeholder in its place (`uv 0`, an empty `bytes`, a zero
  digest, a count of 0) so that the stream stays well formed. A required
  operand (`child`, `string`, `type`, `sym`) that is 0 is such an id.
- **`child*` with 0.** `ANNOTATE.b` says 0 is the empty list and is
  written as a count of 0; `NONNULL.a` says nothing, and 0 there is not a
  list, so it is `Unaccounted("AttrNode/NONNULL.a")`.
- **Conditional rows.** `CONSTRUCTOR`/`DESTRUCTOR` `.a-priority` is
  present (`uv?`) exactly when `flags-priority-dependent` is clear and
  `.a-expression` (`child?`) exactly when it is set; each writes its
  presence byte either way. `GSL_OWNER.b`/`GSL_POINTER.b` (`type?`) is
  written from the word; a word that disagrees with `flags-has-type` (set
  with 0, or clear with a type) is `Unaccounted("AttrNode/<kind>.b")`.
- **`LOOP_HINT.b`** is unpacked with `LoopHint::unpack`; a word that does
  not pack back to itself holds a value no row names and is
  `Unaccounted("AttrNode/LOOP_HINT.b")` (the unpacked fields are written
  regardless). `SWIFT_PARAM_ABI.a` past `ParamAbi`'s values is
  `Unaccounted("AttrNode/SWIFT_PARAM_ABI.a")`.
- **`NO_SANITIZE.a`** is the set `no_sanitize_set(a, b)`; its names are
  written as `bytes*sorted` (sorted by the encoded bytes, §1.3, so by
  length first). A member with no name (a bit at 60 or above) is
  `Unaccounted("SanitizerSet/0")`; `no_sanitize_set` cannot make one
  today.
- **`DIAGNOSE_IF`'s bits** are Kiln's private constants
  (`kiln_sema/src/diagnose_if.rs`); `attrs.rs` writes them by hand with
  that citation.

## `AnnotArena`

- **`of_decl`** is one list over the chain (first to last, each
  declaration's annotations in stored order), written as
  `record Annotation*`.
- **`of_base`** is a count of the base-specifiers of the definition
  (`Ast::definition`, 0 when there is none or it is not a class), then,
  for each in order, its list (`AnnotArena::of_base` of the first
  declaration and the index) as `record Annotation*`. A base without an
  annotation writes a count of 0, so moving an annotation from one base to
  another changes the unit.
- **`Annotation`** writes `value` (`value?`), `written_type` (`type`),
  `expr` (`child`) in row order; `decl` and `loc` write nothing.

## Rows Kiln does not reach

Listed in the handback of `docs/wp/WP-030.md` with the Kiln sites; they
stay in `tests/tables/untested.txt`: the kinds only another target has
(`ARM_LOCALLY_STREAMING`, `ARM_NEW`, `BUILTIN_ALIAS`, `TARGET_VERSION`,
and the rows under them), `NOCF_CHECK` (only under
`-fcf-protection=branch`), `AttrSyntax` `Declspec` (only under
`-fms-extensions`), the `b` words Kiln never sets (`DEPRECATED.b`,
`NODISCARD.b`, `UNAVAILABLE.b`, `ALLOC_ALIGN.b`), `WEAKREF.a` (0 once
checked), `TARGET_CLONES.b` (always 1), `USING_IF_EXISTS` (never attached)
and `CLEANUP` (every node is indeterminate by `CLEANUP.a`).

Some rows are tested by a unit test, not by a differ pair, because Kiln
changes another row along with them. An `interrupt` handler gets an
implicit `USED`, so `X86_INTERRUPT` is pinned by `s10_1_x86_interrupt`.
The bits whose pair also changes an operand or the type
(`DESTRUCTOR.flags-priority-dependent`, `MODE.flags-deferred`,
`GSL_OWNER`/`GSL_POINTER` `flags-has-type`) are pinned by
`s10_1_bits_with_their_operands`.
