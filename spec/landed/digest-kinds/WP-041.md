# WP-041 — what a unit's own spellings hold beyond their profiles

What `crates/slip_digest/src/spelling.rs` and its three sites read into
`spec/digest-kinds.md` §4.2 rule 1 and §4.4 ("The mark", "Spellings"),
and where the code departs from the letter of `docs/wp/WP-041.md`.
`Area::Spelling` is gone: no unit is `Pending(Spelling)`.

## Decisions as built

1. **A found set** is written as the full walk writes an
   `UnresolvedLookupExpr`'s: `Walk::write_refs_sorted` (a count, the
   `Ref`s sorted by their bytes, duplicates removed, a using-shadow as
   its target). Pinned: `spelling_tests::the_set_is_written_sorted_and_without_duplicates`.
2. **The list** is one per unit, written after the unit stream
   (`spelling::write_unit_list`, called by `units::write` and
   `Walk::content_hash` before the stream is finished): `count`, then per
   entry `uv` kind and payload (`1` `Found` `ref*sorted`, `2` `Oper`
   `ref*sorted`, `3` `Alias` `ref`, `4` `Chosen` `count` and `ref?` each).
   The unit's entries are collected in walk order in `UnitState::facts`;
   a key and a content digest take a fresh `UnitState`, so nothing they
   read lands in the unit that asked. Unit streams are prefix-free, so the
   list appended after one is unambiguous. An empty set is an entry (its
   place keeps the entries of two spellings aligned) but does not make the
   list due; a unit with no due entry writes nothing more. Pinned on the
   whole pair-test corpus by `spelling_tests::a_list_changes_only_the_units_that_write_one`
   (with lists switched off, the units whose digest moves are exactly as
   many as the lists written, and no key moves, over every pair-test
   directory). Of the pair tests that existed before this package, the
   units that write a list are those of
   `differ/_/dependent-decltype-own-lookup-set`,
   `differ/_/dependent-decltype-earlier-spelling-added` and
   `equal/_/decltype-requalified`, all `Pending(Spelling)` before.
3. **Walk order** is the type's structure (rule 2) and, in an
   expression, profile mode's order (pre-order, children as
   `expr_profile::node` pushes them). Pinned by
   `spelling_tests::the_order_of_two_spellings_changes_no_digest` (eleven
   shapes, each with the two declarations in both orders) and
   `the_order_of_two_partial_specialisations_changes_no_digest`, and by
   `equal/_/spelling-one-profile-two-spellings`.
4. **Instantiated declarations** (decision 4). Kiln rebuilds every
   instantiation-dependent expression when it substitutes
   (`Substituter::needs_rebuild`, `kiln_sema/src/templ/subst/exprs.rs:30`:
   any `TYPE_VALUE_INST` dependence, whatever the depth of the parameter
   it names), so a member template of `A<int>` has an expression of its
   own, a fresh `ExprId`; the rebuilt unresolved name keeps the pattern's
   found set (`Substituter::callee`, `exprs.rs:2341`, `unresolved_decls`),
   which is the set lookup found at the definition, the member's meaning.
   Rule 2 applies as it stands. Pinned:
   `spelling_tests::an_instantiated_member_reads_the_patterns_found_set`
   (two member templates, one that names `T` and one that does not; both
   rebuilt, both with the set `{f(int)}` though `f(long)` is declared
   before the explicit instantiation).

## The rules as built

- **Rule 1** (`spelling::expr`, `node`): an explicit stack mirroring
  `expr_profile::node`. Entries: `Found` per `UnresolvedLookupExpr` (not a
  variable template template parameter's `V<args>`); `Oper` per
  expression with an `oper_lookups` set (unary, binary and compound
  assignment operators, `kiln_sema/src/expr.rs:3537,4046`); `Chosen` per
  `CXXNewExpr` with an allocation or deallocation function and per
  `CXXDeleteExpr` with a deallocation function. Types are read as
  written: a cast's `cast_written` type, else the node's.
- **Rule 2** (`spelling::ty`): the arms are exhaustive over `TypeView`; a
  type not instantiation-dependent is skipped. A function declaration's
  own exception specification is not read (`own_fn`): its unit walks it
  in full (`ty-exception-spec`).
- **Rule 3, the three sites**:
  - `Walk::absorb_type` now takes the written type and calls
    `left_out_of_type` when `Walk::unit_level()` (no key, no type digest,
    no profile written into the unit: `Walk::spelling_off`). Callers:
    `write_type` (every `type` row of a unit stream, with the type the
    row holds) and `decl_node` `ty-type` (the declaration's written type,
    `own_fn` for a function);
  - `expr_dep::profile_expr` at unit level reads its expression
    (`left_out_of_expr`); `expr_dep::profile` of a `ProfileId` has only
    the first spelling and is `spelling/profile` when its walk counted a
    fact; `Walk::write_args` at unit level writes the canonical list and
    reads the list it was given (`left_out_of_args`); a default template
    argument (`templ::decl_maps`) reads the argument as written
    (`left_out_of_arg`);
  - `templ::partial_spec_info` reads `PartialSpecInfo::args`, the
    arguments as written.
- **Rule 4**: `Typedef`, a `Using` type naming a typedef-name, and an
  alias template specialisation (its pattern) are an `Alias` entry when
  the typedef-name's own aliased type as written makes a list due (or
  carries a cause), computed once per walk from depth 0
  (`Walk::alias_due`). The alias template specialisation's arguments are
  read. Pinned: `differ/_/spelling-alias-template`,
  `differ/_/spelling-member-alias`,
  `spelling_tests::an_alias_holds_its_set_and_its_user_the_ref`,
  `a_use_through_an_alias_lists_the_alias`.
- **Rule 5**: see below.
- **Rule 6**: see the survey.

## The survey (rule 6)

Every row §7's full walk writes for an expression and profile mode does
not (the list of `spec/landed/digest-kinds/WP-036.md`, "Rows left out in
profile mode", and the `ColdExprData` and `TemplateTables` expression
maps), classified: (a) not meaning, (b) in the profile's words in another
form, (c) a left-out fact, which raises the mark and has a list entry.

| Row | Class | Why |
|---|---|---|
| `ExprNode.ty` | (b) | a dependent expression's type is a function of its operands, in the profile; the types Kiln's profile writes (casts, literals, constructions) are written |
| value category, object kind | (b) | functions of the kind and the operands; an explicit cast's is written |
| `ExprDeps`, flag bits Kiln does not read | (b) | computed from the operands; the bits that are choices (ADL, `global`, `array`) are written |
| implicit nodes (`ImplicitCastExpr` cast kind and base path, `ConstantExpr` value, temporaries, cleanups) | (b) | conversions and cleanups follow from the operand's and the target's types; a user-defined conversion's function is a member of a type in the profile |
| `SubstNonTypeTemplateParmExpr.a` | (b) | it is its replacement `b` |
| `OpaqueValueExpr` numbering | (a) | the walk's own numbering |
| literal radix and spelling | (a) | spelling (digest §1 rule 2) |
| `DeclRefExtra` qualifier | (b) | the declaration referred to is written as its `Ref` |
| `DeclRefExtra` `found_decl` | (a) | the using-shadow it was found through; the full walk writes its target too (`write_ref`) |
| non-dependent explicit arguments of a reference to a non-template | (b) | the `Ref` is the specialisation's |
| **`UnresolvedLookupExpr.b`** | **(c)** | the found set: `Found` |
| **`oper_lookups`** | **(c)** | the definition context's non-member operators of a dependent operator (`TemplateTables`, written by `templ::expr_maps` in full, read by no profile: `kiln_ast/src/types/profile_expr.rs` does not name it): `Oper`. Found by this survey |
| **`NewExtra` `operator_new`, `operator_delete`** | **(c)** | the functions a resolved `new` chose where it was written (a placement `new` with an overload declared between two spellings): `Chosen`. Found by this survey |
| **`CXXDeleteExpr.b`** | **(c)** | the same for `delete`: `Chosen` |
| `CXXNewExpr` `pass-align`, `CXXDeleteExpr` sized and aligned | (b) | follow from the chosen function |
| `CXXDependentScopeMemberExpr` canonical qualifier | (b) | the spelled qualifier is written, level by level |
| `size_of_pack_origin`, `size_of_pack_partial`, `pack_index_origin` | (b) | the pack is in the profile by position; what a partial substitution made of it is in the substituted type |
| `RequiresExpr`, `ConceptSpecializationExpr` stored result (`aux`) | (b) | a function of the operands, in the profile |
| a requires-expression's parameters beyond their types | (a) | names and locations |
| `CXXConstructExpr` construction flags | (b) | what resolution computed from the kind, the constructor (`Ref`) and the arguments |
| `CXXDefaultArgExpr`, `CXXDefaultInitExpr`, `default_imm`, `default_arg_rewritten` | (b) | the callee's or the field's, which the profile names |
| `cast_written` | (b) | the canonical cast type is written; the written one is read for the list |
| `syntactic_list`, `union_field`, `designators` | (b) | the semantic form follows from the written one and the type |
| `expr_begin`, `end_loc`, `member_op_loc`, `template_kw`, `trait_rhs_loc`, `pseudo_dtor_first`'s location | (a) | locations |
| `pseudo_dtor_name` | (b) | the destroyed type is written |
| `source_loc` | (a) | a value from a position (digest §9) |
| `fp_round` | (c), not done | the floating-point rounding state where a non-dependent floating operation was written; Kiln's profile does not read it. Not added: a hazard (below) |
| `member_overload`, `offsetof_*`, `splice_args` | n/a | their kinds are walked in full: in the bytes |

Rule 6's count test: `spelling_tests::left_out_is_raised_where_the_list_has_an_entry`
walks every expression of every pair-test side in profile mode and
reads it (`spelling::expr`), outside any type, and compares the
expressions where `Walk::left_out` was raised with those where a due
entry was read: equal on all of them.

## Departures

- **The trigger is the unit's own spelling, not the mark** (decision 2's
  wording, and §4.4 before this package, say the list follows a marked
  type). The mark is the first spelling's: with `g`'s `decltype(f(t))`
  spelled first where lookup found nothing and `h`'s after `f(long)`,
  `h`'s type is unmarked and the mark alone would leave `h` equal when
  `f(long)` is added: a wrong `equal`, reproduced before the change by
  `differ/_/spelling-first-spelling-empty`. So a unit writes its list
  whenever its own spelling holds a due entry. Decision 2's test is
  restated accordingly: the units that change are the units that write a
  list.
- **Rule 4 reads an alias template specialisation's arguments**: they are
  the user's spelling (`Id<decltype(f(T()))>`), not the alias's.
- **Site 3 reads `PartialSpecInfo::args`**, not
  `TemplateTables::args_as_written`, which Kiln fills only for explicit
  specialisations (`kiln_sema/src/templ/spec.rs:923,936,1034`).
- **Two more kinds of fact**: `Oper` and `Chosen` (the survey), each a
  variant of the one list.
- **`Walk::write_args` and default template arguments** are sites too:
  a unit stream writes canonical argument lists directly
  (`expr_targs`, `member_overload`), and the list it holds is its own.
- **`fp_round`** is a left-out fact not in the list (see the hazard).

## Hazards (in `spec/digest-kinds.md`, "Hazards accepted for now")

- A canonical operand without a spelling is `spelling/<site>` only when
  marked; with an unmarked first spelling it is determinate and writes no
  list. No unit stream holds such an operand in the corpus or the
  sources tried. If Kiln ever substitutes from a canonical operand
  (`profile_expr(p)`, the first spelling's expression, in
  `kiln_sema/src/templ/subst/types.rs`), the result reads as the unit's
  own spelling while it is the first spelling's set: a Kiln question
  (what such an instantiation means), not reproduced here.
- `fp_round`: two spellings of one profile under different
  `#pragma STDC FENV_ROUND` states are one type to Kiln and to the
  digest.
